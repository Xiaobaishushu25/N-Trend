# 评分参数研究实施与复现

本功能是离线研究工具，不读取账户凭据，不连接经纪商，不修改原行情库、正式评分或实盘配置。

## 固定实验

- 主窗口：2026-07-31 00:00至2026-10-31 00:00，北京时间，左闭右开；另读45个自然日预热。
- 22品种、实际合约分别计算；冻结映射仅用于候选所属主合约选择。历史映射原时点是否可知尚未验证，全部结果属于开发研究。
- 预警15分钟柱收盘后等待原突破入场；初始结构止损按tick向扩大距离方向对齐。
- 一手、预计开平各1tick及费用后的计划损失不超过500元。跳空后实际风险和亏损可以超过500元，原样保留。
- 净200元固定目标不受S1封顶；目标按可观察入场行情、1tick成本预测和费用上界换算，压力场景不重新放宽目标。
- 12根等待、入场所在柱计为第1根、第5根最大有利运行不足0.5R退出、第60根期限退出；只在已完成15分钟柱检查。
- 0/1/2tick分别回放，S1独立对照。费率为冻结快照，不冒充逐日实际账单。
- 同一分钟两种单调路径分歧保留未知。双方已终结时释放占用；仍存在未终结路径或资料中断则不伪造释放。
- 原始特征、交易结果与拟合产物独立；所有未知和未结束状态保留，不填零。

## 入口与接口

Rust增加独立研究命令：

```powershell
cargo build -p n-core --bin signal-quality --offline
target/debug/signal-quality.exe factor-scan --input PREPARED/scan-input.jsonl --out NEW_SCAN_DIRECTORY
```

Python依赖本机已有的NumPy、SciPy和Matplotlib，不依赖scikit-learn；运行版本固定在`scripts/factor-study-requirements.txt`，阶段manifest另保存实际Python与库版本。统一入口：

```powershell
python -X utf8 scripts/research_factor_study.py run --protocol scripts/factor-study-v1.json --out research-runs/factor-study/NEW_RUN
```

输出目录必须不存在。分阶段恢复使用新的阶段目录，原产物不覆盖：

```powershell
python -X utf8 scripts/research_factor_study.py prepare --protocol PROTOCOL.json --out NEW_PREPARED
python -X utf8 scripts/research_factor_study.py scan --input NEW_PREPARED --out NEW_SCAN
python -X utf8 scripts/research_factor_study.py replay --input NEW_SCAN --out NEW_REPLAY
python -X utf8 scripts/research_factor_study.py diagnose --input NEW_REPLAY --out NEW_DIAGNOSE
python -X utf8 scripts/research_factor_study.py fit --input NEW_REPLAY --out NEW_FIT
python -X utf8 scripts/research_factor_study.py verify --input NEW_REPLAY --fit NEW_FIT --diagnosis NEW_DIAGNOSE --out NEW_VERIFY
python -X utf8 scripts/research_factor_study.py report --input NEW_REPLAY --fit NEW_FIT --diagnosis NEW_DIAGNOSE --verification NEW_VERIFY --out NEW_REPORT
```

可用`scan --scanner target/release/signal-quality.exe`选择优化编译的扫描器。扫描invocation保存可执行文件哈希。Python阶段分别保存源文件快照、输入、输出及代码哈希；校验输入变化时拒绝继续。

## 数据对象与阶段产物

|阶段|主要产物|
|---|---|
|prepare|协议、日历、费用快照、逐合约分钟线/15分钟柱、缺口清单、覆盖与跨来源冲突|
|scan|`FactorSnapshotV1`、25/50/75%前缀一致性、Rust规则快照|
|replay|`TradeLabelV1`、开平费用与成交明细、歧义路径、可释放占用时间|
|diagnose|特征字典、训练期分箱、单项曲线、A×B条件面、相关组、固定/重新拟合消融、权重邻域|
|fit|全部候选尝试、时间折、`FitArtifactV1`、逐折预测与门槛、订单账本、辅助R/达标概率模型|
|verify|Decimal逐笔金额/R核算、前缀与身份、样本集合、训练截止时间、品种占用与哈希核验|
|report|中文报告、JSON汇总、单项及A×B静态图|

`FactorSnapshotV1`显式区分预热候选与主窗口候选。预热候选用于初始化订单/持仓，不混入近期成绩或近期训练。模型只接收已列入字典的预警时原始特征，结果字段不进入特征矩阵。

verify另使用独立检查器核对逐笔入场/退出参考价与源分钟行情、按交易日的Decimal费用。目标有利跳空保守按固定目标减不利滑点退出，不计开盘改善；约定价可能不在该分钟OHLC内，逐条单列，不宣称该价格实际被观察成交。report在原扫描可执行文件哈希仍匹配时归档该可执行文件。

## 验证与候选选择

- 近期：前30个交易日训练，此后每5日评估。内部使用此前最后两个5日窗口；只用截止前已经结束的交易训练，同A跨界组从训练中隔离。
- 扩展：在协议`validation`中设置`schedule="monthly"`、`initial_months=6`，起点改为2025-07-31；按月外层与此前3个月内层验证。仍是开发资料。
- 内部训练不足200个独立结构组不拟合；复杂模型至少300组且每个设计列5组。
- 当前公式比较原权重、等权、单模块和256个固定种子的Sobol联合权重；映射研究比较线性岭、三结点分段线性样条和5种预登记交互。
- 所有拟合、填补、标准化、分箱、相关组与门槛只用相应训练资料。惩罚候选固定为0.1、1、10、100。
- 每个内部窗口至少20笔完成、已入场结果确认比例至少95%；完成数不低于基线50%，回撤不超过基线加200元，2tick净金额不低于基线。按合计净元、再平均净元、再简单程度选择。
- 没有候选通过则回退原版。v1>=70保留为单独对照，不冒充与前20%相同筛选力度。
- 5日联合日期块重采样2000次，另查10日敏感性。固定账本区间不代表整个选模搜索的不确定性。Spearman与BH只作探索描述。
- 不根据单个参数的系数或单月正收益自动修改正式权重。

## 测试

```powershell
python -X utf8 -m unittest discover -s tests -p test_factor_study.py -v
python -X utf8 -m unittest discover -s tests -p 'test_score*.py' -v
cargo test -p n-core quality:: --lib --offline
```

重点覆盖：净200元费用换算、多空tick取整、跳空超风险、同分钟歧义、止损后行情不得回填盈利、无跟随边界、跨日费用、未知占用、训练结果可用时间、同A隔离、纯交互效应、相关复制特征与不可变产物。

## 前瞻与兼容

旧扫描、评分DTO和正式交易路径不调用新研究模块。研究候选冻结文件不等于上线或已经采集新信号。

登记的首次新信号复核要求60个交易日和200笔完成交易，平均净元相对基线至少改善10元、配对日期改善区间下界>0、2tick净收益为正、覆盖与回撤要求均成立。中途改版必须重新冻结。

研究运行目录被Git忽略。源码与协议可随代码保存，移动或备份项目时还需保存实际运行产物和对应输入数据。
