# 开仓净期望模型首轮优化结果

2026-10-23。已实现同规则标签、四组特征、净期望推断、按时间前推训练与校准、机会重新接纳、滑点压力及开仓信息预览。首轮试验没有证明模型相对简单规则有稳定增益，维持研究模型状态，未接入生产或自动开仓。

## 试验口径

- 固定之前冻结的`score3_friction20`一手S1候选：评分≥3、风险≥10 tick、成本占风险≤20%、净目标空间覆盖完整止损、保留第五根无跟随退出。没有改变识别、目标、止损或评分公式。
- 22品种、冻结的3014个预警中，共2735条进入统一研究机会池。使用原S1执行账本重新匹配标签，不复用旧分档模型的胜负。
- 全期一跳规则有336条闭合标签、同品种一槽接纳后232条。仅用当时已平仓的槽位接纳样本训练；未知路径不补成0收益或亏损。
- 固定三个向前预测窗口：8月17日至9月7日、9月7日至9月28日、9月28日至10月23日。数据实际截至10月22日11:25；每段使用43、85、138条已观测历史标签训练。共对1970条预警生成每个模型的预测。
- 从8月17日空仓开始，每个筛选器重新计算同品种槽位，跨验证段持续占用；并非每段清仓重置。没有账户资金上限和跨品种总敞口限制。
- 每次成交一跳为主情景、两跳为压力。两跳使用同一套一跳训练模型和相同筛选决定，不重新选择阈值；执行账本和机会占用按压力情景重新计算。
- 费用使用原公开费率快照，含白糖往返2元覆盖规则，不是历史逐日真实合约账单。滑点已在成交价里，不重复扣除。
- 所有历史此前已经参与开发。本次为滚动开发试验，没有新增独立验证样本。

## 实现的模型

分类器为有L2正则的简单Logistic，缺失值中位数、标准化参数仅从拟合段估计，标准化值固定裁到±5。固定正则10、600轮，不搜索参数。四组模型全部披露：

|组名|特征数|内容|
|---|---:|---|
|legacy7|7|原7种输入，重新拟合相同S1标签，作为特征对照|
|space_cost|13|推进速度改ATR/根，加入目标RR、风险tick、净目标R、完整止损R、摩擦占比、预警追价R|
|shape|19|增加A/B根数、速度比、方向归一化的收盘位置、实体和影线|
|context|24|再增加冻结的60分钟趋势方向/强度、因果ATR波动比、时钟周期项；事先指定为主模型|

ATR从完整15分钟原始三根5分钟组合计算；缺根或未完成的组合不参与。仅用过去TR，确认换月时重置波动历史。趋势来自原冻结预警快照；没有用后来确认K线、未来成交价、MFE/MAE或最终持仓时间作为输入。

训练末25%的预警日期用作时间校准段，并清除跨校准起点的拟合标签；尾部样本不足时保留原概率，不用验证段补齐校准。第二、三段分别有29、43条校准样本，首段不足，使用恒等校准。校准使用向恒等映射收缩的正斜率Sigmoid。

净期望由同一政策下的盈利概率及条件平均盈亏组合。条件幅度按事先固定的计划RR段`<2 / 2—3 / ≥3`估计，向训练期整体均值收缩20个先验样本；不是完整收益分布模型，也没有把单笔目标距离和超时风险全部精确建模。所有条件均值来自当时已知训练标签。

每组比较两种固定筛选：校准净胜率≥50%；预估净期望R>0。主模型始终是context，没有因结果而切换成表现更好的其他特征组。

## 主要结果

下表为相同滚动预测窗口、筛选后重新接纳的一手交易。金额均为可定价闭合部分，不是完整账户权益。

|方案|1跳闭合数|1跳净胜率|1跳平均净R|1跳净额|2跳净额|
|---|---:|---:|---:|---:|---:|
|简单规则|189|39.15%|+0.2077|+10115.68|+6934.45|
|原7特征，胜率≥50%|38|31.58%|-0.2267|-1515.08|-1704.11|
|空间成本，净期望>0|152|39.47%|+0.2421|+10416.22|+8682.30|
|完整特征，胜率≥50%|62|37.10%|+0.0594|+1821.27|+1294.13|
|完整特征，净期望>0（主模型）|152|40.13%|+0.2472|+10216.04|+8306.13|

完整特征的净期望筛选比单纯50%胜率门槛保留了更多低胜率、高盈亏比机会，在本次开发数据上更合理。但它相对简单规则的优势仍不足：

- 一跳现金增量仅+100.36元；交易数减少37笔，累计净R反而减少1.6894R。平均单笔R提高不等于总净优势提高。
- 两跳现金增量+1371.68元、累计R增量+5.2913R，存在继续观察的线索。
- 一跳增量现金的描述性联合分块区间约[-4718.81,+4294.21]元；两跳约[-3141.26,+5202.84]元，均跨零。累计R增量区间也都跨零。该诊断对固定接纳账本重采样，不是在重采样路径上重新运行容量，也未校正多次开发试验。
- 一跳规则接纳4条未知，主模型接纳3条未知；两跳也分别为4和3。未知结果没有计成0。可定价部分的增量还不足以消除这些未决结果的影响。

从接纳变化看，主模型一跳保留150个原接纳机会，新增5笔闭合交易，同时去掉42笔闭合交易和1条歧义机会。新增5笔赚594.11元，但去掉的42笔原本也净赚493.75元，差额即约100.36元。不能把所有被过滤交易说成“避免的亏损”。

## 模型预测能力仍弱

固定同一规则接纳、可闭合子集上的三段指标：

|特征组|第1段AUC|第2段AUC|第3段AUC|第1/2/3段Brier Skill|
|---|---:|---:|---:|---|
|原7特征|0.497|0.508|0.470|-0.032 / -0.036 / -0.048|
|空间成本|0.571|0.478|0.472|+0.034 / -0.064 / -0.054|
|形态扩展|0.492|0.465|0.447|-0.094 / -0.079 / -0.073|
|完整特征|0.483|0.448|0.490|-0.092 / -0.101 / -0.029|

这些模型是用新S1标签重新训练的对照，不能与旧分档标签下的AUC直接比较并称为升降。新增特征没有稳定改善概率估计，复杂组在有限样本下有过拟合迹象，不能因为某组收益略高就晋升。

## 尾部和稳定性

主模型一跳已实现现金回撤从7103.31元降至6700.55元，最长已实现连亏从11次降至7次；但最差交易仍为-8.6R、-1462元，最差10%平均从-2.000R变为-2.020R，没有修复极端亏损。

一跳主模型8/9/10月可定价现金净额分别为-33.53、+9822.56、+427.01元；两跳为-233.53、+9330.86、-791.20元，仍依赖9月。两跳剔除现金最大的5笔盈利后剩-317.87元。

没有足够极端标签训练条件尾部概率，因此输出的是训练期尾部事件计数与“证据不足”，没有伪造精确跳空概率，也没有新增“必能把亏损限制在某金额”的规则。

## 现在可以使用的产物

新增离线研究代码：

- `scripts/entry_model.py`：因果特征、净空间价格边界、简单概率与条件幅度模型、序列化推断。
- `scripts/research_entry_model.py`：冻结输入核验、按时间训练/校准、18个模型/规则执行情景、接纳变化、压力比较与报告。
- `tests/test_entry_model.py`：14项用例，覆盖未来结果隔离、校准清除、报价单位归一化、完整K线、换月重置、价格边界、未知占用、筛选后重新接纳及模型序列化。

最终批次：`research-runs/entry-model-20261023-v2/`。

- `models.json`保存各段与最终四组研究模型。最终模型只使用10月22日11:25之前已知的232条闭合训练记录，其中133条拟合、99条时间校准；不是用未来数据补训练。
- `entry-previews.jsonl`保存每个滚动预警的拟成交价、止损、S1、计划止损风险、净空间允许的价格边界、预估净R、概率及原因。它是历史时点的研究预览，未连接实时页面。
- 价格边界只表示“净空间覆盖完整止损”的结构条件，不是模型正期望的保证。价格改变后需要重新检查空间和重新评分，当前没有部署实际拟成交时的模型复核。
- `warning-snapshots.jsonl`、`predictions.jsonl`、`admission-ledger.jsonl`保存全链路审计。
- `summary.json`包含全部四组特征、两种筛选、两档滑点、分段/月份/品种、接纳变化及增量区间。`verification.json`保存核验结果。

`research-protocols/entry-model-shadow-20261023-v1.json`冻结了模型包与试验指纹，资格false；没有启动前瞻采集器或后台任务。该文件供未来新数据纸面比较使用，不等于已经开始前瞻验证。
