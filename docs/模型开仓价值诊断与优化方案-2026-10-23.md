# 模型开仓价值诊断与优化方案

2026-10-23。本轮读取当前代码和冻结V3运行，重新核算491条滚动验证预测；未重训、晋升模型或修改生产交易配置。

## 复核结论

当前模型有少量排序信息，但尚未证明能提供可靠的开仓净优势。主要问题是交易目标与使用方式容易错位、输入缺少收益与成本结构，以及高概率样本不足。单纯把开仓门槛从50%提高到60%不能解决这些问题。

|概率门槛|笔数|实际净胜率|平均净R|累计净R|剔除最大5笔盈利后R|
|---|---:|---:|---:|---:|---:|
|全部|491|39.51%|-0.3093|-151.8564|-157.0865|
|≥50%|76|50.00%|-0.0563|-4.2782|-9.0577|
|≥60%|15|53.33%|+0.1073|+1.6088|-3.0786|
|≥70%|5|40.00%|+0.1182|+0.5908|-1.2932|

≥50%这组平均预测概率56.44%，实现净胜率50%，平均盈利0.769R、平均亏损0.882R，说明胜率提高后仍然可以亏钱。由这组已实现盈亏反算的盈亏平衡胜率约53.41%，仅用于解释结果，不能倒灌成入场时已知阈值。

≥60%这组平均预测概率68.12%，只有15条、8赢7亏，不能当成68%可交易胜率。剔除前5笔只作收益集中度诊断，不代表剩余样本是新验证集。

三段AUC为0.5711、0.5765、0.5353，Brier Skill为+0.0198、-0.0198、-0.0050。后两段概率误差没有优于训练期常数基线。全样本平均预测39.93%与实际39.51%接近，也不能证明高概率区间准确。

## 代码中直接看到的限制

1. 当前合同是预警时预测、突破后按分档规则执行的`warning-breakout-net-v3` / `live-partial-continuous-08r-v3`。它不等于收盘开仓、下一根退出，也不等于新研究的一手S1方案。更换执行规则需要重新生成标签和版本，不能复用旧概率解释。
2. `v3::WHITELIST`只有A/B幅度ATR、A段速度、回撤比、预警量比、评分、方向共7项；没有原S1空间、止损距离、费用/滑点占比和持仓时段。
3. `a_speed`为报价点数/根。例如不同品种相同形态可能因为报价单位不同而取值差很大。对混合样本统一标准化不会消除品种单位差异；应试验ATR/根等无量纲速度。
4. 预警形态中的K线收盘位置、实体、影线、段长等已有字段未进入白名单；日内趋势与波动环境也未进入当前7特征。遗漏不等于补入后一定有效，需按组验证。
5. 当前训练/OOF只覆盖原策略可闭合、特征完整、同品种非重叠的样本。不能用这491条代表全部3014个预警，更不能直接当作新S1规则的筛选验证。
6. 当前代码的前瞻资格检查和challenger隔离有必要保留。静态改状态或重新拟合历史数据不构成验证。

## 建议的改造顺序

### 1. 先固定一种真实要交易的动作

主实验可沿用已冻结的`score3_friction20`候选：预警后突破入场、一手、原S1/原止损、既有无跟随规则、评分≥3、风险≥10 tick、净空间和成本占比门槛。它仅是现成的研究基线，并非已获实盘资格；本轮没有按模型结果重新选择策略。

如果要在触发K线收盘才开仓，则另建“收盘决策”模型：决策时重新计算剩余S1空间、现价到止损距离、确认K线信息和下一可成交报价。该模型可以使用已完成的确认K线，预警模型不能使用未来确认信息。两个时点分开保存特征快照和标签合同。

任何实际拟成交价变化，都要重新检查空间；预警时的高分或高概率不是允许追价的通行证。

### 2. 把模型目标改成交易净期望，并补充尾部指标

第一版保留简单模型：预测相同退出政策下的净盈利概率，同时用训练窗口估计或拟合条件净盈利/净亏损幅度，得到：

```text
预估净期望R = P(净盈利) × E[净R | 净盈利, 当前信息]
              - P(非盈利) × E[-净R | 非盈利, 当前信息]
```

非盈利分支包括0收益，若有0收益样本需计入其条件均值。此处盈利/亏损幅度已扣同一套费用与滑点，不再重复扣成本。只有概率和条件幅度属于相同决策时点、相同策略、相同成本口径时才可组合。

固定目标/止损的两结果近似可用于解释盈亏平衡，但当前还有无跟随、超时、跳空等结果，不能只用`p×S1收益-(1-p)×原止损`冒充完整期望。跳空会使损失超过计划1R。

样本不足时，条件幅度先采用训练期收缩均值作基线，不按品种切成几十个小模型。另行记录亏损超过1R/2R、跨休市风险及持有时间；尾部模型没有足够极端样本时输出证据不足，不能假装风险概率精确。

### 3. 只增加事前可得、含义清楚的特征

按三组做有限对照，避免一次引入大量自由度：

|特征组|拟加入内容|作用|
|---|---|---|
|空间与成本|剩余S1距离/风险、风险tick、费用/风险、预估滑点/风险、当前追价R|区分有胜率但没有净空间的交易|
|形态归一化|A段ATR速度、A/B根数、速度比、预警实体/影线/收盘位置|减少报价单位影响，描述形态细节|
|环境与时段|仅已完成60分钟趋势、事前波动水平、量比、距交易休市时间、已知假期长度|区分顺势环境、噪声与持仓风险|

以预警时模型为例，不能把未来成交滑点、最终持有时长、未来MFE/MAE或最终合约切换结果作为输入。休市时间需要可追溯的交易所日历；不把自然日星期直接当交易日。

手续费按具体合约、开平今昨及生效日期匹配；当前公开快照仍然是研究情景。两跳压力保持同一事前成本预测，不按压力结果重新挑样本。

### 4. 验证模型是否给简单规则增加了价值

固定三个对照：规则基线；规则加净胜率；规则加净期望。统一一手、同品种单机会、同一成本和执行政策。先在训练期内选特征/拟合与校准，再向前测试；不能在验证段找最佳概率阈值。

每段训练只使用决策时已结束且已观测到标签的历史交易，清除持仓标签跨越切分点的样本；标准化和缺失填补也只在训练段拟合。未成交、过滤、未结束、路径未知分开保留；完整政策回报可单独计量未成交机会，但不得把未知交易当0收益或负标签。新筛选器改变机会占用后，必须重跑接纳账本，不能只截取旧账本里成功接纳的交易。

核心比较是新增净收益与R、压力下的收益、已实现回撤、尾部和机会数；同时保留AUC、Brier与分段校准。总样本里常数概率看起来准确，不代表能区分值得交易的机会。概率校准应使用独立于拟合数据的时间段；单调校准主要修正概率尺度，不能凭空增加排序信息。[概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)

当前7—10月历史已参与大量策略开发，新的滚动结果仍只能叫开发诊断。冻结模型、特征、成本、筛选条件及源代码指纹后，再累计新的纸面记录。沿用最新研究协议的60个新增交易日、200笔可定价闭合机会作为集中复核检查点，并报告独立机会组；数量到达不自动通过。反复试验后挑历史最好方案会增加选择偏差。[回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

### 5. 最终开仓界面应给出可执行信息

建议展示：决策时点和执行方案、拟成交价、止损、目标、每手计划风险、预计成本、净空间比、预估净R、可支持该结论的样本范围，以及“可候选/等待/空间不足/证据不足”的原因。

达到候选标准仍需当前空间、风险与机会占用检查。价格超过净空间允许范围则撤销候选，不靠提高胜率阈值放行。模型初期只筛选是否参与，不按概率提升手数；新的净期望输出在验证前仍应标为研究估计。
