# 候选策略实现与模拟测试规格

版本：`paper-candidates-spec-20261023-v1`。整理日期：2026-10-23。时区统一为 `Asia/Shanghai`。

本文是一份实现规格，覆盖旧策略对照 `LEGACY` 和研究候选 `P0/P1/P2/P3`。正文给出输入、公式、状态机、撮合、会计、异常处理与验收要求；文末附冻结参数、费用表和N信号生成算法全文。脱离当前源码版本后仍可查阅，不必只凭函数名猜测实现。

本版推荐顺序为 **P2主测试、P3分布对照、P1简洁对照、LEGACY旧逻辑对照，账户足够再加P0**。这只是模拟测试安排，尚无新增独立验证。先前协议把P3称为主要分布候选，本文调整测试优先级，但不改变任何历史规则或结果。

## 1. 策略范围与版本边界

这些候选共用项目原有的N形态预警。它们改变预警之后的筛选、持仓管理和退出，不重新训练模型，也不使用预测胜率决定仓位。`entry_score`是规则评分，不是胜率或概率。

必须区分三个层次：

1. **信号层**：在已完成15分钟K线上识别N结构，输出不可回写的预警快照。正文第3节定义接口，配套附录定义生成算法。
2. **策略层**：按本文P0～P3过滤、触价入场、退出，独立记录每组结果。
3. **执行层**：历史5分钟OHLC回放，或新增实时行情模拟成交。两个执行版本分别报告，不混为同一条业绩曲线。

版本名约定：

|名称|含义|
|---|---|
|`research-v5`|已经报告的历史5分钟双路径回放；需按第11节保留兼容细节|
|`paper-tick-v1`|本文第12节定义的新增实时模拟执行；不能承诺精确复现历史净额|
|`LEGACY_NATIVE`|旧策略按实际冻结配置运行，保留原分仓、退出和执行行为|

P0不是LEGACY的完整复刻。把P0叫“原成本过滤对照”可以，把它叫“当前项目原策略”不准确。

## 3. 输入接口、时间与不可变快照

### 3.1 最小输入

```text
SignalSnapshot {
  source_version, signal_schema_version,
  symbol, instrument_id, contract_mapping_version,
  direction: "up" | "down",
  warning_ts, available_at,
  s0_ts, s1_ts, s2_ts,
  s0_price, s1_price, s2_price,
  entry, stop, target, risk,
  entry_score, warning_kind,
  tick_size, multiplier,
  atr14_as_of, atr14, context_complete,
  rollover_known_at_warning
}
```

`symbol`是研究品种键，如`MA0`；`instrument_id`是实际可交易合约，不能用连续合约代码下单。`available_at`记录系统真正收到并确认预警的时间，禁止把晚到信号倒填成预警收盘时即可交易。

历史输入字段映射：`entry_score = ReplayEvent.setup_features.setup_quality`，`target = ReplayEvent.target`，`warning_ts = ReplayEvent.warning_ts`。`trigger_features`、既有`outcome`、`evaluation`、未来`entry_ts`及未来盈亏都不是策略输入。

预警身份键：

```text
event_key = symbol + "|" + direction + "|" + s0_ts + "|" + s1_ts
            + "|" + s2_ts + "|" + warning_ts
```

同一实例同一键只处理一次，重启后也不能重复下单。不同实例各自处理同一信号。若上游生产路径另有合并规则，应冻结该版本；不能自行增加“同一S0/S1/S2永远只做一次”去重后仍宣称复现本次研究。

### 3.2 输入检查

价格、评分、tick、乘数、ATR等参与运算的数值必须有限；tick和乘数必须大于0。方向只能为两个枚举值。定义`d=+1`代表做多，`d=-1`代表做空，要求：

```text
R_plan = d * (E - S) > 0
d * (T0 - E) > 0
abs(input.risk - R_plan) <= 事先冻结的数值容差
```

其中`E=entry`，`S=stop`，`T0=原S1目标`。无效输入拒绝并记录原因，不能通过调换止损方向、把目标抬到1R或补零来“修好”P0～P3的信号。

价格与金额分开：`tick_size`是一个最小报价单位对应的价格距离；`multiplier`是一手每一个价格单位的人民币盈亏。`tick_value = tick_size × multiplier`。

### 3.3 时间约定

原始行情为5分钟**结束时间标签**：09:05代表此前5分钟，09:15代表09:10～09:15。预警09:15只能使用截至09:15已完成的数据；历史交易从`bar.datetime > warning_ts`的5分钟区间开始。实时交易从`available_at`之后收到的有效行情开始。

休市不凭空补K线，午休、夜盘间隔、周末、长假不能按墙上时间累计15分钟桶。交易日与自然日期分开保存。新增模拟使用实际合约行情的交易日字段；历史推断方法见第11节。

## 4. 上游N预警如何生成

本轮应复用项目当前前向识别器，并固定版本。若要在另一语言实现，本文[附录D](#appendix-d)给出本次读取的具体函数与常量，不能用“随便找三个摆动点”替代。

核心定义如下：

1. 逐根推进已完成15分钟K线，每次只向识别器提供截至当前预警K线的前缀；至少22根才开始尝试。形态ATR20是20个真实波幅的简单平均，不是Wilder平滑。
2. 同时寻找fine和large两级形态、多空两个方向。fine摆动点窗口为左右各2根、合并间隔8；large为左右各5根、合并间隔10。用于确认摆动点的右侧K线必须在当前前缀内。
3. 当前预警K线本身作为候选S2端点：做多取该K线低点，做空取高点。S0来自已确认摆动点；S1取S0与S2之间的反向极值，同价优先较晚者。
4. A段根数包含S0，至少3根；B段不包含S1，至少2根。fine检查`S1.index-S0.index≤16`、`S2.index-S1.index≤12`；large分别≤48、≤32。注意A段根数与索引差相差1。
5. 做多`A=S1-S0`、`B=S1-S2`；做空`A=S0-S1`、`B=S2-S1`。只接受回撤比例B/A为[0.20,0.80]的A/B/C级。B段中途触及或越过S0，或内部发生超过B净幅度一半的深V折返，结构无效。具体等级、速度、实体衰减及选优顺序见附录。
6. 拒绝微型N：A幅度小于S1处3倍ATR20，且B幅度小于`max(S2处ATR20,5个价格单位)`时拒绝。A段至少有一根放宽定义的同向趋势K；S0到预警之间不能包含已知换月标记。
7. 预警形态包括干净实体吞没`strong`、满足严格条件的长影线`wick`、连续至少两根反向收盘并越过锚点开盘价的`cumulative`。详细影线、实体和锚点判定见附录。
8. 评分为`0.60×A段质量 + 0.20×B段质量 + 0.20×预警K质量`。累积覆盖封顶3.9，长影线封顶3.0；没有额外趋势加分。本轮不训练或调用机器学习模型。
9. 每个方向、每根预警K只保留评分最高的有效候选。相同分保留识别器先产生的候选，不能事后按利润选形态。

预警价格公式，`H_w/L_w`为预警K的高低点：

```text
buffer = max(0.1 * ATR20_at_warning, 1.0)  // 1.0是价格单位，不是1 tick
做多：E = H_w + tick_size; S = S2 - buffer; T0 = S1
做空：E = L_w - tick_size; S = S2 + buffer; T0 = S1
R_plan = abs(E - S)
```

评分和价格在预警时冻结，之后不随新K线重画。P2/P3新增ATR14是另一套独立上下文特征，不能替换上游形态的ATR20。

## 5. P0～P3共同的预警过滤

按下面顺序检查，并保存每项布尔结果和中间数值。拒绝后该信号终止，不等行情变好再重新激活同一键。

### 5.1 评分和最小止损

```text
entry_score >= 3.0
R_plan / tick_size + 1e-6 >= 10
quantity = 1
```

这里保留的是“拒绝止损距离小于10 tick”的改进，不是只做止损小于10 tick的交易，也不是把不足10 tick的止损强行移远。

### 5.2 费用函数与往返摩擦20%过滤

所有过滤均按一手计算。费用函数：

```text
fee(rule, price) = rule.fixed_yuan_per_lot
                   + rule.notional_rate * price * multiplier

C_bound(open_price, close_price) =
    fee(open_rule, open_price)
    + max(fee(close_today_rule, close_price),
          fee(close_yesterday_rule, close_price))
```

白糖SR按用户明确的往返合计2元/手覆盖：`C_bound=2`，不再叠加普通开平费。比例费率`0.0001`表示万分之一，不能再除以一万。

预测滑点固定`g=1 tick/边`。定义：

```text
F_plan = E + d * g * tick_size
S_exit_plan = S - d * g * tick_size
friction_yuan = 2 * g * tick_size * multiplier
                + C_bound(F_plan, S_exit_plan)
friction_yuan <= 0.20 * R_plan * multiplier + 1e-7
```

**20%过滤只在预警时执行。** 现有研究没有在实际拟成交时再跑一次20%过滤。拟成交时会重查净空间与实际止损距离。若新增第二次20%过滤，必须另起策略版本，不能沿用本版历史数字。

压力回放实际滑点改为2 tick，预测门槛的`g`仍为1；不能悄悄把预警筛选也收紧到2 tick。

### 5.3 目标与净空间过滤

给定拟成交价`F`，定义初始实际风险价格距离：

```text
R = d * (F - S)
P0/P1/P2: T(F) = T0
P3:       T(F) = F + d * min(d * (T0 - F), 2 * R)
```

P3等价于多头取`min(T0,F+2R)`，空头取`max(T0,F-2R)`。它只缩短原目标，不能把目标延长到2R。

定义净收益、完整止损损失：

```text
T_exit = T(F) - d * g * tick_size
S_exit = S    - d * g * tick_size
reward_net = d * (T_exit - F) * multiplier - C_bound(F,T_exit)
loss_full  = d * (F - S_exit) * multiplier + C_bound(F,S_exit)
allow_net_space = loss_full > 0 AND reward_net + 1e-7 >= loss_full
```

在预警时先令`F=F_plan`计算一次；触发时按当时拟成交价再计算一次。分母包含完整结构止损、止损平仓滑点和往返手续费。不能只用毛收益/毛止损，也不能把“到1R后保本”当成必然，从而缩小分母。

## 6. P2/P3新增的ATR14过滤

原始5分钟K线按结束标签向上归入15分钟桶。只接受**恰好3条原始记录，且最后一条时间等于桶末时间**的上下文桶；输入应事先保证时间唯一、顺序正确、5分钟网格合法。

```text
bucket_end = 当日00:00 + ceil(当日已过分钟数 / 15) * 15分钟
```

特别地，午夜00:00仍归00:00桶，和前一日23:50、23:55同组，不得强制归到00:15。OHLC分别取首条开盘、最高高、最低低、末条收盘，成交量求和。

```text
TR[0] = H[0] - L[0]
TR[i] = max(H[i]-L[i], abs(H[i]-C[i-1]), abs(L[i]-C[i-1]))
ATR14[i] = mean(TR[i-13 : i+1])
```

第14个完整上下文桶开始有ATR。它是简单均值，包含当前已收盘的预警桶。筛选要求：

```text
latest_complete_context.ts == warning_ts
ATR14有限且 > 0
0.75 <= R_plan / ATR14 <= 2.50
```

范围两端包含，使用未四舍五入的原值。不得改成`实际成交R/ATR`、ATR20、Wilder ATR或未完成预警桶。ATR只在预警筛选，不重画止损，不随持仓更新目标。

研究ATR14上下文直接由原始行情构造，未按换月对TR做额外归零，也未每个会话重置。若未来改用实际合约分段、换月重置或更严格缺口检查，应单独版本化并说明历史差异。

## 7. 条件单、触发、机会冲突

### 7.1 状态机

```text
NEW -> REJECTED_WARNING / PENDING
PENDING -> EXPIRED / INVALIDATED / REJECTED_ENTRY / OPENING
OPENING -> OPEN / CANCELLED / UNKNOWN
OPEN -> EXITING -> CLOSED
任一执行不确定状态 -> UNKNOWN -> 核实成交、仓位后恢复
```

`OPENING/EXITING`用于真实异步委托，历史瞬时成交可以直接从PENDING转OPEN或OPEN转CLOSED。一个拒绝或到期的信号不算亏损；UNKNOWN不能记为零盈亏，也不能当成已空仓。

### 7.2 触发与入场复核

预警后，做多价格向上触及E，做空向下触及E时尝试入场。未入场前先触及结构止损S，信号失效。同一条行情已经越过止损时，失效判定优先于入场。

历史中：正常穿越E以`E+d×实际滑点×tick`拟成交；开盘直接跳过E，以该根开盘价加不利滑点拟成交。不能仍假定跳空时成交在E。

```text
F = observed_reference + d * execution_slip_ticks * tick_size
chase = d * (F - E)
max_chase = max(0.20 * R_plan, 2 * tick_size)
```

按如下顺序检查：休市停开窗口；`chase <= max_chase+1e-6`；原S1仍在盈利方向；按F重新算目标与净空间；`R_actual/tick+1e-6 >= 10`。失败即终止该信号，不分配虚构成交，不自动追单重试。

通过后冻结`F、R_actual、T(F)、S、费用版本、策略参数版本`。R的分母此后始终使用这次实际初始风险，不能跟随止损变动。P0～P3始终一手，不因评分高、某品种近期赚钱或连续亏损而增减仓。

### 7.3 等待与持仓桶计数

历史兼容计数不是“预警后固定180分钟”或“入场后固定900分钟”。它随实际观察到的15分钟桶推进：

```text
last_bucket = ""; waited = 0; held = 0
每根 warning_ts 之后的5分钟K开始前：
    bucket = legacy_bucket_end(bar.ts)  // 兼容细节见11.2
    若 bucket != last_bucket:
        last_bucket = bucket
        若尚未入场: waited += 1
        否则: held += 1
    若尚未入场且 waited > 12: EXPIRED，不再处理该根入场
    处理该根价格路径
    若该根首次入场: held = 1
    仅 bar.ts == bucket 时评估5桶/60桶退出
```

第一桶即计1，即使只剩一个5分钟片段。入场发生于某桶中间，也以该桶为持仓第1桶。第13个等待桶开始前到期；第5个持仓桶结束时检查无跟随，第60个桶结束时检查最长持仓。午休不会创建空桶。

### 7.4 同品种机会冲突

P0～P3每个实例各自限制同一`symbol`最多一个已经接纳的入场机会，不分多空；不同实例不互相占槽。**不是账户全市场只能持有一单，也不是预警一出现就锁住品种12桶。**

本次历史报告先逐信号独立回放，再按拟入场区间做槽位筛选：按`entry_interval_end、warning_ts、event_key字典序`依次处理；若已有同品种机会结束时间`>=`本次开始时间，则本次拒绝。相同5分钟时间标签不能先平一笔又开另一笔；没有入场的确定拒单不占持仓槽。UNKNOWN按第11.4节保守占用。

实时实现对应为：可以观察多个PENDING，但同一行情序号的入场竞争先按`warning_ts、event_key`排序；接纳一个时立即占槽，包括尚未回报成交的OPENING；其余已触发机会终止为`blocked_symbol_slot`，不排队补做。尚未触发的条件单保留到自己的触发、失效或到期。第12节定义事件先后，避免串行处理顺序改变结果。

## 8. P0～P3退出规则

固定原始结构止损S；P0/P1/P2固定原S1；P3固定按实际初始风险算出的较近目标。**没有到1R减仓、保本或移动止损。** 一手不可拆半手。

方向统一判定：

```text
stop_hit   = d * (observed_price - S) <= 0
target_hit = d * (observed_price - frozen_target) >= 0
favorable_r(price) = d * (price - F) / R_actual
MFE_R = max(0, 所有已观察到的favorable_r)
MAE_R = min(0, 所有已观察到的favorable_r)
```

退出原因及顺序：

|优先顺序|条件|动作|
|---:|---|---|
|1|盘中已触发止损或目标|退出1手，分别`stop`或`target_s1`|
|2|到达长假14:45检查点仍持仓|全部退出，`pre_holiday`|
|3|P1/P2/P3进入周末最后时段退出窗口|全部退出，`pre_weekend`|
|4|已完成持仓第60桶|收盘退出，`time_exit`|
|5|恰好第5桶结束且`MFE_R < 0.5`|收盘退出，`no_follow`|

第5桶MFE恰好0.5R不退出；第5桶未退出后，不在第6、7桶再次以这个条件退出。无跟随使用持仓以来最大有利波动，不是当前浮盈；即使当前回亏，只要曾达到0.5R，也不满足此项。

历史桶末退出按本根收盘价减不利平仓滑点；正常盘中止损按S减不利滑点，跳空越止损按实际开盘价减不利滑点，不把亏损硬截成−1R。正常目标按目标减不利平仓滑点；开盘跳过目标也不额外享受优于目标的成交价。

注意P3即使2R封顶，实际净盈利仍会因双边滑点、手续费低于2R；止损也可能因跳空、流动性和执行失败超过1R。

## 9. 长假与周末规则

### 9.1 所有P组的长假处理

每次长假使用明确、版本化的日历窗口`{block_from,flat_at,last_close,reopen}`。在节前最后交易日日盘14:30停止新入场，14:45退出全部候选持仓，不按浮盈亏区别处理。

历史冻结窗口：

|长假|停止入场|退出检查点|末次日盘收盘|复市|
|---|---|---|---|---|
|中秋|2026-09-24 14:30|09-24 14:45|09-24 15:00|09-28 09:00|
|国庆|2026-09-30 14:30|09-30 14:45|09-30 15:00|10-08 09:00|

这些日期只用于本期复现。下一期必须加载覆盖测试期间、按交易所及合约核验的日历；不从“下一根K离得很远”反推假期。原文件直接引用上期所公告，跨交易所例外尚需补充，不能把它当作所有未来市场的完整日历。

历史结束标签为保守处理，尝试入场的5分钟标签若满足`block_from <= ts <= reopen`，整段都拒绝，包括复市首根可能以09:00标记的区间；正常09:05标签的复市区间可成交。实时模式按真实时间`[block_from,reopen)`停开，并记录该边界差异。

14:45缺少可用价格时记执行未知，不能拿节后第一根价格倒填成节前平仓。P组不因普通午休或普通夜间休息自动退出。P0仍可以跨普通周末。

### 9.2 P1/P2/P3周末处理

目标是避开**周末最后一个可交易会话之后**的缺口，不是所有品种周五14:50统一退出。

|冻结会话类型|周末最后收盘|停开与退出窗口起点|
|---|---|---|
|无夜盘|周五15:00|周五14:50|
|23:00夜盘|周五23:00|周五22:50|
|23:30夜盘|周五23:30|周五23:20|
|01:00夜盘|周六01:00|周六00:50|
|02:30夜盘|周六02:30|周六02:20|

历史谓词是：当前标签距离该品种下一会话收盘在0～10分钟，且该收盘的星期、时分符合上表。进入窗口的第一根可用5分钟收盘价加不利滑点退出；窗口内触发的新入场拒绝。若窗口内行情全部缺失，不在周一补造周五成交，保留UNKNOWN诊断。

SF/SM在最终离线研究中按**无夜盘**覆盖，未修改共享生产日历。实时模式以核验后的合约交易时段为准，不能照搬默认23:00回落值。上述时段是复现配置类型，不是对未来所有品种交易时间的保证。

## 10. LEGACY旧策略对照的实现与保留方式

优先直接复制待比较旧实例的策略定义、执行配置和合约参数，接入独立模拟账户，命名`LEGACY_NATIVE`。它用于回答“新策略是否优于项目当前行为”，不要求伪装成P0。

当前代码可核验的核心逻辑如下：

- 评分≥2.5可参与；评分≥3.5为Large，否则Small。默认Large=2手、Small=1手，实际取实例配置且至少1手。即使把Large手数改成1，它仍是Large退出类别，不能自动当Small。
- 保留结构止损；旧逻辑原目标空间≤计划风险时，把有效目标预设成1R。P0～P3不做这个替代。
- Small：盈利到实际初始1R时全部退出；亏损到当前止损时退出。
- Large：到1R先平**1手**；只有这1手的成交确认后，才设置`lot1_closed=true`，将余仓止损提到入场价。没有确认不能提前保本。
- 余仓历史最高有利波动达到1.6R后，连续保留距峰值0.8R的保护：`lock_R=MFE_R-0.8`；不足1.6R时`lock_R=0`。多头新止损`max(旧止损,F+lock_R*R)`，空头`min(旧止损,F-lock_R*R)`，从不放宽。
- 剩余仓位还可以到原S1退出；有效S1不超过1R时，剩余仓位主要按保本/跟踪退出，不额外伪造第二个更远目标。
- 第5桶MFE<0.5R无跟随退出和60桶时间退出仍存在。

旧策略须以真实成交腿核算，不能把2手1R分批退出算作两笔独立交易来虚增胜率。一个信号的所有开平腿归为一笔；初始货币风险为`R_actual*multiplier*initial_volume`。

若需要只比较逻辑差异，可另建`LEGACY_CONTROLLED`：明确统一行情、费用、机会槽、假期限制，并逐项列明与NATIVE的差别。它的结果不能冠以“旧实例原样”。不按本轮历史直接给旧策略或新策略增加评分加仓。

## 11. 历史research-v5的精确复现

### 11.1 双路径回放

每根预警后的5分钟K，复制当前状态，两份分别走`O→H→L→C`和`O→L→H→C`。先处理开盘，再逐线段处理；没有入场前，顺方向穿越E可触发，反方向先穿越S则失效。入场后，顺方向线段先检查目标，反方向线段检查止损。只统计入场后出现的MFE/MAE，目标触发后不再把该根剩余高低点计入。

两条路径要求状态、入场/退出时间、退出原因、剩余手数、入场价、累计毛点数、每条成交腿时间/价格/手数/offset/reason一致；毛点数与成交腿价格容差`1e-7`。持仓未结束时，保护标记、止损、峰值也必须一致。终态路径不要求相同的MFE/MAE，最终沿用第一条路径，因此极值诊断本身仍有路径局限。

不一致记`ambiguous`，保存两份诊断，不取更赚钱者、不取平均、不硬算亏损。即使一致，也只说明两条单调路径一致，不证明所有盘中振荡都能同价成交。

### 11.2 计数兼容细节：不能把两个桶函数混用

新增ATR上下文使用第6节正确处理午夜的桶函数；但v5回放等待/持仓计数和原上游信号仍复用旧聚合函数。旧15分钟桶末：

```text
legacy_bucket_end(ts) = 当日00:00
    + max(ceil(当日已过分钟数/15),1) * 15分钟
```

因此旧函数会把00:00标成00:15，00:00本身不触发桶末退出检查。这是复现限制，不能在复现时顺手修复后继续引用原213/203笔净额。新增实时版在第12节明确采用正确的已完成桶事件，单独版本记录；以后修复旧聚合需另跑对照。

### 11.3 缺数据、换月、尾部未结束

历史引擎逐根处理时检查：时间不可解析→`missing_data`；相邻处理K间隔>5且≤180分钟，若下一应有5分钟点落在日历交易时段→`missing_data`。超过180分钟缺口没有被这条局部规则完全覆盖，不能把研究结果称为完整连续行情认证。

预警之后至当前处理K之间出现已确认换月记录→`rollover`，不跨连续合约跳变强行结算。持仓跨过预定长假退出点但该点没有报价→`missing_data`。数据末尾仍持仓→`unfinished`；仍待触发→`pending`。这些状态均不进入可定价已平仓P&L。

### 11.4 未知机会的槽位占用

未知状态集合：`ambiguous,missing_data,rollover,unfinished,pending`。已知入场则从其入场标签占槽；若歧义只在一条路径入场，从两路径最早可能入场标签占槽；仍无入场信息时从预警占槽。

占用结束使用保守最大研究窗口：取该品种预警之后第72个满足分钟可被15整除的原始K线时间；不足则取归档末尾。它是研究诊断上界近似，不是模拟账户收到UNKNOWN后可以自动释放仓位的指令。确定已结束机会按终态时间释放；结束时间与新开始标签相同仍算冲突。

### 11.5 费用重估与日期

回放成交价已经包含滑点。Rust结果先按`fee_ticks=0`输出毛金额，Python费用重估再逐腿扣手续费一次，不能另外再扣一轮滑点或旧2.5 tick费用代理。

历史交易日由所有归档品种日盘日期集合推断：06:00～18:00用当日；18:00以后映射下一观察日盘日期；06:00以前映射不早于当日的第一个日盘日期。周五夜盘、周六凌晨通常因此归周一，但这是归档推断，非结算单认证。

开、平属同一推断交易日用平今，否则平昨；SR往返覆盖2元/手。比例手续费按每条**含滑点的成交价格**和实际手数算。冻结快照未重建历史费率变更、真实合约逐日映射和柜台舍入规则。

## 12. 新增实时paper-tick-v1执行规范

本节是将研究意图落到新增模拟测试的执行约定，不是声称历史回放已经包含逐笔盘口、网络延迟或委托排队。模拟实现必须将实际执行日志与research-v5诊断分开。

### 12.1 数据与成交模型

所有P组订阅同一份实际合约行情，行情包含`instrument_id,exchange_ts,received_at,sequence,last,bid1,ask1,bid_volume1,ask_volume1,trading_day`。序号单调，重复消息忽略，乱序或断档进入数据异常流程。

建议初版采用确定性的盘口市价模拟，配置冻结为：

```text
matching_model = "top_of_book_next_quote"
base_extra_slip_ticks = 0       // 盘口买卖价差已体现在bid/ask，不重复当作滑点
stress_extra_slip_ticks = 1     // 另存压力账本，不冒充历史slip2
max_quote_age_ms = 2000
latency_ms = 0                  // 显式的理想化基准，不伪称网络真实延迟
```

触发行情只产生委托意图；在之后第一条同合约、可用且时间新鲜的报价上，买入按ask1、卖出按bid1，再加配置的不利extra slip，并按实际涨跌停限制检查。报价侧数量不足1手时等待后续有效报价，不凭空成交。延迟、陈旧阈值、额外滑点是新模拟执行参数，未从历史优化获得；如改动须冻结新执行版本。

将净空间及追价检查放到实际尝试分配模拟成交之前，以该报价对应的拟成交价计算；不通过则撤销入场意图并终止信号。若交易所模拟账户返回真实委托成交，则以其成交回报为准，不能先按本地理想价记OPEN；实际成交后记录与拟成交价的差异，不能事后删除不利成交。

实时触发与MFE/MAE先按有效last判断，对手价决定成交。P3目标和结构止损可保留为非整数tick的内部阈值，用合法报价跨越判断；不得把非tick价格作为交易所限价订单提交。若改用交易所挂单、价格取整或不同触发价，另起执行版本并明确取整方向。

没有有效盘口就记录`unavailable_quote`，不退回last虚构bid/ask。为了单独比较历史假设，可以并行保存“同信号1/2 tick研究账本”，但必须标成合成成交结果。

### 12.2 同一行情事件的处理顺序

```text
1. 校验行情、同步已确认成交和已知持仓，持久化必要状态。
2. 对已有持仓按当前last判止损/目标；若需退出，锁定退出任务。
3. 处理日历、无跟随、时间退出任务；已有退出任务不重复创建。
4. 同一品种若本事件发生退出或仍有OPENING/OPEN/EXITING/UNKNOWN，禁止新入场。
5. 检查PENDING的止损失效、到期、日历停开；再收集本事件触发者。
6. 按warning_ts、event_key排序，接纳首个符合条件的机会并立即占槽。
7. 委托意图从下一有效报价才允许撮合；成交回报驱动状态变更。
```

实时版不允许在同一行情序号平旧仓再开新仓；它允许后一条报价在已确认平仓后入场，因此仍比历史“整个5分钟标签禁止重叠”更精细。必须报告这类差异数量，不能悄悄强行对齐业绩。

### 12.3 桶末与日历定时器

实时版按第6节正确午夜归属构造桶。入场所在桶为持仓第1桶，之后只在有真实交易数据的桶推进；第5桶收盘用截至桶末的MFE判断，第60桶收盘发退出意图。不得使用桶末之后才到达的新高回填该桶MFE。

14:30停开、14:45退出、周末最后会话前10分钟均由日历定时器触发，不能仅等待“恰好那个秒数有一条行情”。计时器触发后在下一可用报价执行，记录计划时刻、意图时刻、首个可交易时刻、实际成交时刻。失联或封板未成交时，保留真实持仓和未完成退出任务，不能到了周末就把模拟仓位清零。

周末新入场从退出窗口起停止，直到下一交易会话复市。若长期假日同时生效，较早的停开/退出规则优先。长假复市时间按核验日历解锁；不能因程序重启而清除停开窗口。

### 12.4 超时、重启和账户约束

P组一手持仓；退出失败仍占槽。重启必须恢复事件去重、条件单、待成交委托、冻结目标/风险、MFE、桶编号、成交腿及退出任务。未经确认的委托不因超时直接视为撤销成功；新增入场先核对账户持仓。

本轮研究不限制5万元，也不计算五万元收益率。策略比较先记录不受资金筛选影响的研究账本；若模拟账户资金有限，额外记录`insufficient_margin`与当时可用资金、所需保证金，资金受限的可执行曲线单列。P组使用相同初始余额和保证金版本；不把资金拒单算进信号失败率或亏损笔数。

旧策略原样组可能有日亏损限制、风险百分比、人工确认和不同手数。跨组既看原账户表现，也看单位初始风险R、每手金额、共同信号子集，不能直接把不同风险规模的现金总额排名当作策略优劣。

## 13. 费用、盈亏和指标公式

每一笔交易对应一个信号，所有退出腿归并：

```text
gross_yuan = sum(d * (exit_fill[j] - entry_fill) * exit_qty[j] * multiplier)
commission = open_fee + sum(close_fee[j])
net_yuan = gross_yuan - commission
initial_risk_yuan = R_actual * multiplier * initial_qty
net_R = net_yuan / initial_risk_yuan
win = net_yuan > 0
loss = net_yuan < 0
flat = net_yuan == 0
win_rate = wins / priced_closed_trades
cash_PF = sum(positive net_yuan) / abs(sum(negative net_yuan))
R_PF = sum(positive net_R) / abs(sum(negative net_R))
```

无平仓时胜率应为null；没有亏损时PF用null并注明分母为0，不随意输出一个极大数。保持完整浮点/定点精度，最终展示再保留两位。真实柜台的费用舍入规则单独记录。

每组都输出：预警数、各过滤拒绝数、触发数、冲突数、实际入场数、已平仓数、未知数、净胜率、毛额、手续费、净额、总R、平均R、PF、平均盈利/亏损、连亏长度、最差单笔、持仓时长、退出原因、MFE/MAE、实现与完整权益回撤。

历史已实现现金回撤按退出时间和event_key排序，从累计净额曲线计算，不含浮盈亏。新增模拟还需按行情更新`equity=cash+unrealized_pnl`，分别报告完整权益回撤；不能把冻结研究的约3305元称为P2真实账户最大回撤。

### 13.1 用户关注的收益分布

分品种给出：交易数、净额、平均/总R、费用、胜率、1 tick/2 tick研究结果、实际模拟结果、至少10/20笔标记。零交易品种标“无样本”，不能记成已验证保本。

```text
positive_product_sum = sum(max(product_net,0))
top3_positive_share = 三个最大正品种净额之和 / positive_product_sum
top3_total_net_share = 三个最大正品种净额之和 / 全部品种净额
```

两种分母分别报告，不能混用。盈利品种数量之外，同时报告盈利≥500元、≥1000元的数量作为描述统计，并报告这些品种平均R和样本数；金额阈值不是自动交易白名单或新的选优门槛。

对单笔、退出交易日、退出自然日期、品种分别做：删最好K、删最差K、两端各删K，K取1/3/5/10；金额和R分别排名，只在正贡献中取最好、负贡献中取最差，不重复删除同一分组。这些只是事后诊断，不允许删除后回补其他机会，不能把删最差后的表现宣称可实盘实现。

交易日优先用真实交易所字段；自然日期敏感性也保留。月度同时报告按预警月与按退出月，复现原报告时主表使用预警月。单列跨长假/周末持仓数与跳空贡献，避免再次把节后缺口当成一般信号优势。

## 14. 必须落盘的日志与数据表

最低建议五类追加式记录，主键均包含`account_id,instance_id,strategy_id,strategy_version,execution_version`：

## 15. 策略层伪代码

```python
def on_signal(sig, cfg):
    if seen(sig.event_key): return
    persist_immutable_signal(sig)
    validate_input(sig)
    if sig.entry_score < 3.0: reject('score_below_min'); return
    if sig.risk / sig.tick + 1e-6 < 10: reject('risk_ticks_below_min'); return
    if not friction20_at_warning(sig): reject('friction_above20'); return
    if cfg.use_atr:
        if sig.atr_as_of != sig.warning_ts or not sig.context_complete:
            reject('atr_unavailable'); return
        if not finite_positive(sig.atr14): reject('atr_unavailable'); return
        if not 0.75 <= sig.risk / sig.atr14 <= 2.5:
            reject('atr_out_of_range'); return
    proposed = sig.entry + sig.d * sig.tick  # 固定1 tick预测
    if not net_space(sig, proposed, target(sig, proposed, cfg)):
        reject('filtered_net_rr_plan'); return
    create_pending(sig, max_wait_buckets=12)

def attempt_entry(sig, proposed_fill, now, cfg):
    if in_entry_block_window(now, cfg): reject('calendar_block'); return
    if same_symbol_slot_occupied(sig.symbol): reject('blocked_symbol_slot'); return
    if sig.d * (proposed_fill - sig.entry) > max(.2 * sig.risk, 2 * sig.tick) + 1e-6:
        reject('unfilled'); return
    if sig.d * (sig.target - proposed_fill) <= 0: reject('invalid_target'); return
    R = sig.d * (proposed_fill - sig.stop)
    T = target(sig, proposed_fill, cfg)
    if not net_space(sig, proposed_fill, T): reject('filtered_net_rr_fill'); return
    if R / sig.tick + 1e-6 < 10: reject('filtered_actual_risk'); return
    reserve_slot_and_submit_one_lot(sig, proposed_fill, R, T)

def target(sig, F, cfg):
    if not cfg.cap_2r: return sig.target
    R = sig.d * (F - sig.stop)
    return F + sig.d * min(sig.d * (sig.target - F), 2 * R)

def on_completed_holding_bucket(pos):
    # 盘中退出、长假和周末任务应已先处理；退出委托未完成不得重复下单
    if pos.exit_pending: return
    if pos.held >= 60: request_exit('time_exit')
    elif pos.held == 5 and pos.mfe_r < .5: request_exit('no_follow')
```

### 16.2 止损不硬截1R

```rust
        if let Some(date) =
            chrono::NaiveDate::from_ymd_opt(self.year, self.month as u32, self.day as u32)
        {
            if let Some(dt) = date.and_hms_opt(self.hour as u32, self.minute as u32, 0) {
                let exp = dt + chrono::Duration::minutes(mins as i64);
                return Self {
                    year: exp.year(),
                    month: exp.month() as i32,
                    day: exp.day() as i32,
                    hour: exp.hour() as i32,
                    minute: exp.minute() as i32,
                };
            }

        let mut d = self.day;
        let mut h = self.hour;
        let mut min = self.minute + mins;
        while min >= 60 {
            min -= 60;
            h += 1;

        while min < 0 {
            min += 60;
            h -= 1;
        }
        while h >= 24 {

            d += 1;

                m += 1;

                    y += 1;

                if m < 1 {
                    m = 12;
                    y -= 1;
                }
                d = Self::days_in_month(y, m);
            }

            year: y,
            month: m,
            day: d,
            hour: h,
            minute: min,
        }

                }
            }
```

```rust
//! K-line aggregation: derive higher timeframes from the 5m base series.
//!
//! 规则：
//! - 分钟级别按日历桶对齐（floor 到目标分钟数），桶的 ts 记为桶末（与源站语义一致）；
//! - 相邻原始 bar 间隔超过 5 分钟视为会话断裂，即使落入同一日历桶也另起一桶；
//! - 会话首尾不足整桶的 bar 保留为部分桶；
//! - 日线按交易日分组，夜盘（20:00 后）计入次日。

use chrono::{Days, NaiveDate, NaiveDateTime, Timelike};

use crate::fetch::kline::Kline;

pub const BASE_TIMEFRAME: &str = "5m";
pub const BASE_STEP_MINUTES: i64 = 5;
const NIGHT_THRESHOLD_HOUR: u32 = 20;
const TS_FORMAT: &str = "%Y-%m-%d %H:%M:%S";

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]

    M30,
    M60,

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum BucketKey {
    Minute(NaiveDateTime),
    Day(NaiveDate),
}

/// 把升序 5m 序列聚合为目标级别（输入需已按时间排序）。
pub fn aggregate(bars: &[Kline], target: Timeframe) -> Vec<Kline> {
    if bars.is_empty() {
        return Vec::new();
    }
    if target == Timeframe::M5 {
        return bars.to_vec();
    }

    let mut out: Vec<Kline> = Vec::new();
    let mut cur: Option<Bucket> = None;
    let mut prev_dt: Option<NaiveDateTime> = None;

    for bar in bars {
        let Some(dt) = parse_ts(&bar.datetime) else {
            continue;
        };
        let key = bucket_key(dt, target);
        let session_break = target.minutes().is_some()
            && prev_dt
                .map(|prev| (dt - prev).num_minutes() > BASE_STEP_MINUTES)
                .unwrap_or(false);
        let bucket_break = cur.as_ref().map(|b| b.key != key).unwrap_or(true);

        if bucket_break || session_break {
            if let Some(bucket) = cur.take() {
                out.push(bucket.finish(target));
            }
            cur = Some(Bucket::new(key, bar));
        } else if let Some(bucket) = cur.as_mut() {
            bucket.add(bar);
        }
        prev_dt = Some(dt);
    }
    if let Some(bucket) = cur.take() {
        out.push(bucket.finish(target));
    }
    out
}

struct Bucket {
    key: BucketKey,
    open: f64,
    high: f64,
    low: f64,
    close: f64,
    volume: f64,
    hold: f64,
}

impl Bucket {
    fn new(key: BucketKey, bar: &Kline) -> Self {
        Self {
            key,
            open: bar.open,
            high: bar.high,
            low: bar.low,
            close: bar.close,
            volume: bar.volume,
            hold: bar.hold,
        }
    }

    fn add(&mut self, bar: &Kline) {
        self.high = self.high.max(bar.high);
        self.low = self.low.min(bar.low);
        self.close = bar.close;
        self.volume += bar.volume;
        self.hold = bar.hold;
    }

    fn finish(self, target: Timeframe) -> Kline {
        let datetime = bucket_ts(self.key, target);
        Kline {
            datetime,
            open: self.open,
            high: self.high,
            low: self.low,
            close: self.close,
            volume: self.volume,
            hold: self.hold,
        }
    }
}

fn bucket_key(dt: NaiveDateTime, target: Timeframe) -> BucketKey {
    match target.minutes() {
        Some(minutes) => {
            let day_start = dt.date().and_hms_opt(0, 0, 0).unwrap();
            let elapsed_min = (dt - day_start).num_minutes();
            // 源站 5m bar 时间戳为桶末语义：bar 归入“结束时间 >= 自身时间戳”的桶
            let end_min = (((elapsed_min + minutes - 1) / minutes).max(1)) * minutes;
            BucketKey::Minute(day_start + chrono::Duration::minutes(end_min - minutes))
        }
        None => BucketKey::Day(trading_day(dt)),
    }
}

fn bucket_ts(key: BucketKey, target: Timeframe) -> String {
    match key {
        BucketKey::Minute(start) => {
            // 桶末时间戳：start + 目标分钟数；会话首尾的部分桶也按该桶应有的结束时间标记
            let end = start + chrono::Duration::minutes(target.minutes().unwrap_or(5));
            end.format(TS_FORMAT).to_string()
        }
        BucketKey::Day(date) => date
            .and_hms_opt(15, 0, 0)
            .unwrap_or_default()
            .format(TS_FORMAT)
            .to_string(),
    }
}

/// 计算指定时间点在目标周期下的桶末结束时间戳（格式：%Y-%m-%d %H:%M:%S）。
pub fn current_bucket_end_ts(dt: NaiveDateTime, target: Timeframe) -> String {
    let key = bucket_key(dt, target);
    bucket_ts(key, target)
}

/// 交易日：20:00 之后的夜盘归入下一交易日。
pub fn trading_day(dt: NaiveDateTime) -> NaiveDate {
    if dt.hour() >= NIGHT_THRESHOLD_HOUR {
        dt.date() + Days::new(1)
    } else {
        dt.date()
    }
}

}
```

```rust
use crate::analyze::model::{Bar, Swing, Trend60, ATR_PERIOD};

pub fn atr(bars: &[Bar], period: usize) -> Vec<Option<f64>> {
    let n = bars.len();
    let mut tr = vec![0.0; n];
    for i in 0..n {
        tr[i] = if i == 0 || bars[i].rollover {
            // 换月 bar 的“前收盘”来自旧合约，跨合约 gap 不构成真实波动
            bars[i].high - bars[i].low
        } else {
            let pc = bars[i - 1].close;
            (bars[i].high - bars[i].low)
                .max((bars[i].high - pc).abs())
                .max((bars[i].low - pc).abs())
        };
    }

    let mut out = vec![None; n];
    let mut sum = 0.0;
    for i in 0..n {
        sum += tr[i];
        if i >= period {
            sum -= tr[i - period];
        }
        if i + 1 >= period {
            out[i] = Some(sum / period as f64);
        }
    }
    out
}

/// 简单移动平均序列；不足 period 根的位置为 None。
pub fn ma_series(bars: &[Bar], period: usize) -> Vec<Option<f64>> {
    let n = bars.len();
    let mut out = vec![None; n];
    if period == 0 {
        return out;
    }
    let mut sum = 0.0;
    for i in 0..n {
        sum += bars[i].close;
        if i >= period {
            sum -= bars[i - period].close;
        }
        if i + 1 >= period {
            out[i] = Some(sum / period as f64);
        }
    }
    out
}

pub fn trend_flags(bars: &[Bar], atr20: &[Option<f64>]) -> Vec<(bool, bool)> {
    let mut out = Vec::with_capacity(bars.len());
    for i in 0..bars.len() {
        let mut up = false;
        let mut down = false;
        if !bars[i].rollover {
            if let Some(a) = atr20[i] {
                let range = bars[i].high - bars[i].low;
                if range > 0.0 {
                    let body = (bars[i].close - bars[i].open).abs();
                    let body_ratio = body / range;
                    let up_pos = (bars[i].close - bars[i].low) / range;
                    let down_pos = (bars[i].high - bars[i].close) / range;
                    let upper = bars[i].high - bars[i].open.max(bars[i].close);
                    let lower = bars[i].open.min(bars[i].close) - bars[i].low;

                    if bars[i].close > bars[i].open
                        && body_ratio >= 0.75
                        && up_pos >= 0.80
                        && range >= 0.8 * a
                        && upper <= body
                    {
                        up = true;
                    }
                    if bars[i].close < bars[i].open
                        && body_ratio >= 0.75
                        && down_pos >= 0.80
                        && range >= 0.8 * a
                        && lower <= body
                    {
                        down = true;
                    }
                }
            }
        }
        out.push((up, down));
    }
    out
}

pub fn find_swings(
    bars: &[Bar],
    atr20: &[Option<f64>],
    window: usize,
    merge_gap: usize,
) -> Vec<Swing> {
    let n = bars.len();
    if n < window * 2 + 1 {
        return Vec::new();
    }

    let mut raw = Vec::new();
    for i in window..n - window {
        let h = bars[i].high;
        let l = bars[i].low;
        let mut high_ok = true;
        let mut low_ok = true;

        for j in i - window..i {
            if h < bars[j].high {
                high_ok = false;
            }
            if l > bars[j].low {
                low_ok = false;
            }
        }
        for j in i + 1..=i + window {
            if h < bars[j].high {
                high_ok = false;
            }
            if l > bars[j].low {
                low_ok = false;
            }
        }

        if high_ok {
            raw.push(Swing {
                index: i,
                price: h,
                is_high: true,
            });
        }
        if low_ok {
            raw.push(Swing {
                index: i,
                price: l,
                is_high: false,
            });
        }
    }

    let mut merged: Vec<Swing> = Vec::new();
    for s in raw {
        let mut skip = false;
        if let Some(last) = merged.last_mut() {
            if last.is_high == s.is_high && s.index.saturating_sub(last.index) <= merge_gap {
                let atr_now = atr20[s.index].unwrap_or(1.0);
                let tol = (0.5 * atr_now).max(2.0);
                if (last.price - s.price).abs() <= tol {
                    if (s.is_high && s.price > last.price) || (!s.is_high && s.price < last.price) {
                        *last = s;
                    }
                    skip = true;
                }
            }
        }
        if !skip {
            merged.push(s);
        }
    }
    merged
}

// 5档60m趋势：收紧版阈值 2.0ATR + ADX25/18 + 20根不触EMA20(0.3ATR)
// 对齐实盘体感：FG0->RANGE, PB0->WEAK_UP, AU0->STRONG_UP
const TREND_EMA_FAST: usize = 20;
const TREND_EMA_SLOW: usize = 60;
const TREND_ATR_PERIOD: usize = 20;
const TREND_ADX_PERIOD: usize = 14;
const TREND_STRONG_ATR: f64 = 2.0;
const TREND_ADX_STRONG: f64 = 25.0;
const TREND_ADX_WEAK: f64 = 18.0;
const TREND_TOUCH_WINDOW: usize = 20;
const TREND_TOUCH_THRESH: f64 = 0.3;

fn ema_series(values: &[f64], period: usize) -> Vec<Option<f64>> {
    let n = values.len();
    let mut out = vec![None; n];
    if n < period || period == 0 {
        return out;
    }
    let k = 2.0 / (period as f64 + 1.0);
    let mut sma = 0.0;
    for i in 0..period {
        sma += values[i];
    }
    sma /= period as f64;
    out[period - 1] = Some(sma);
    let mut prev = sma;
    for i in period..n {
        prev = values[i] * k + prev * (1.0 - k);
        out[i] = Some(prev);
    }
    out
}

fn adx_wilder(bars: &[Bar], period: usize) -> (Vec<Option<f64>>, Vec<f64>, Vec<f64>) {
    let n = bars.len();
    let mut adx = vec![None; n];
    let mut pdi = vec![0.0; n];
    let mut mdi = vec![0.0; n];
    if n < period + 1 {
        return (adx, pdi, mdi);
    }
    let mut tr = vec![0.0; n];
    let mut plus_dm = vec![0.0; n];
    let mut minus_dm = vec![0.0; n];
    for i in 1..n {
        let h = bars[i].high;
        let l = bars[i].low;
        let ph = bars[i - 1].high;
        let pl = bars[i - 1].low;
        let pc = bars[i - 1].close;
        tr[i] = (h - l).max((h - pc).abs()).max((l - pc).abs());
        let up = h - ph;
        let dn = pl - l;
        if up > dn && up > 0.0 {
            plus_dm[i] = up;
        }
        if dn > up && dn > 0.0 {
            minus_dm[i] = dn;
        }
    }
    let mut atr_w = 0.0;
    let mut p_dm_w = 0.0;
    let mut m_dm_w = 0.0;
    for i in 1..=period {
        atr_w += tr[i];
        p_dm_w += plus_dm[i];
        m_dm_w += minus_dm[i];
    }
    let mut dx = vec![0.0; n];
    // first dx at period
    if atr_w != 0.0 {
        pdi[period] = 100.0 * p_dm_w / atr_w;
        mdi[period] = 100.0 * m_dm_w / atr_w;
        let s = pdi[period] + mdi[period];
        if s != 0.0 {
            dx[period] = 100.0 * (pdi[period] - mdi[period]).abs() / s;
        }
    }
    for i in period + 1..n {
        atr_w = atr_w - atr_w / period as f64 + tr[i];
        p_dm_w = p_dm_w - p_dm_w / period as f64 + plus_dm[i];
        m_dm_w = m_dm_w - m_dm_w / period as f64 + minus_dm[i];
        if atr_w != 0.0 {
            pdi[i] = 100.0 * p_dm_w / atr_w;
            mdi[i] = 100.0 * m_dm_w / atr_w;
            let s = pdi[i] + mdi[i];
            if s != 0.0 {
                dx[i] = 100.0 * (pdi[i] - mdi[i]).abs() / s;
            }
        }
    }
    if n >= period * 2 {
        let mut sum_dx = 0.0;
        for i in period..period + period {
            sum_dx += dx[i];
        }
        adx[period * 2 - 1] = Some(sum_dx / period as f64);
        for i in period * 2..n {
            let prev = adx[i - 1].unwrap_or(0.0);
            adx[i] = Some((prev * (period as f64 - 1.0) + dx[i]) / period as f64);
        }
    }
    (adx, pdi, mdi)
}

pub fn analyze_60m(bars: &[Bar]) -> Trend60 {
    let n = bars.len();
    if n < ATR_PERIOD {
        return Trend60 {
            direction: "RANGE".to_string(),
            ma20: bars.last().map(|b| b.close).unwrap_or(0.0),
            slope: 0.0,
            price_vs_ma: 0.0,
            higher_highs: false,
            higher_lows: false,
            lower_highs: false,
            lower_lows: false,
        };
    }
    let closes: Vec<f64> = bars.iter().map(|b| b.close).collect();
    let e20 = ema_series(&closes, TREND_EMA_FAST);
    let e60 = ema_series(&closes, TREND_EMA_SLOW);
    let a20 = atr(bars, TREND_ATR_PERIOD);
    let (adx, pdi, mdi) = adx_wilder(bars, TREND_ADX_PERIOD);
    // fallback simple ma20/slope for display
    let mut sum = 0.0;
    for i in n - ATR_PERIOD..n {
        sum += bars[i].close;
    }
    let ma20 = sum / ATR_PERIOD as f64;
    let mut prev_sum = 0.0;
    if n >= ATR_PERIOD + 1 {
        for i in n - ATR_PERIOD - 1..n - 1 {
            prev_sum += bars[i].close;
        }
    } else {
        prev_sum = sum;
    }
    let prev_ma = prev_sum / ATR_PERIOD as f64;
    let slope = ma20 - prev_ma;
    let close = bars[n - 1].close;
    let atr20 = atr(bars, ATR_PERIOD);
    let swings = find_swings(bars, &atr20, 3, 8);
    let highs: Vec<&Swing> = swings.iter().filter(|s| s.is_high).collect();
    let lows: Vec<&Swing> = swings.iter().filter(|s| !s.is_high).collect();
    let higher_highs =
        highs.len() >= 2 && highs[highs.len() - 1].price > highs[highs.len() - 2].price;
    let higher_lows = lows.len() >= 2 && lows[lows.len() - 1].price > lows[lows.len() - 2].price;
    let lower_highs =
        highs.len() >= 2 && highs[highs.len() - 1].price < highs[highs.len() - 2].price;
    let lower_lows = lows.len() >= 2 && lows[lows.len() - 1].price < lows[lows.len() - 2].price;

    // determine 5-tier direction if enough data, else fallback to old weak logic
    let direction = if n >= TREND_EMA_SLOW + TREND_ADX_PERIOD * 2 {
        let idx = n - 1;
        let e20v = e20[idx];
        let e60v = e60[idx];
        let atrv = a20[idx];
        let adxv = adx[idx];
        if let (Some(ev20), Some(ev60), Some(av), Some(ax)) = (e20v, e60v, atrv, adxv) {
            let pdiv = pdi[idx];
            let mdiv = mdi[idx];
            let mut touched = false;
            let start = idx.saturating_sub(TREND_TOUCH_WINDOW - 1);
            for j in start..=idx {
                if let (Some(e), Some(a)) = (e20[j], a20[j]) {
                    if (bars[j].close - e).abs() < TREND_TOUCH_THRESH * a {
                        touched = true;
                        break;
                    }
                }
            }
            if close > ev60 + TREND_STRONG_ATR * av
                && ev20 > ev60
                && ax >= TREND_ADX_STRONG
                && !touched
                && pdiv > mdiv
            {
                "STRONG_UP"
            } else if close < ev60 - TREND_STRONG_ATR * av
                && ev20 < ev60
                && ax >= TREND_ADX_STRONG
                && !touched
                && mdiv > pdiv
            {
                "STRONG_DOWN"
            } else if close > ev60 && ev20 > ev60 && ax >= TREND_ADX_WEAK && pdiv > mdiv {
                "WEAK_UP"
            } else if close < ev60 && ev20 < ev60 && ax >= TREND_ADX_WEAK && mdiv > pdiv {
                "WEAK_DOWN"
            } else {
                "RANGE"
            }
        } else {
            "RANGE"
        }
    } else {
        // not enough for 5-tier, use simple range
        "RANGE"
    };

    Trend60 {
        direction: direction.to_string(),
        ma20,
        slope,
        price_vs_ma: close - ma20,
        higher_highs,
        higher_lows,
        lower_highs,
        lower_lows,
    }
}
```

### D.5 N结构与候选选优

来源：`crates/n-core/src/analyze/pattern.rs`，原始第1～389行。

```rust
use crate::analyze::model::{Bar, Dir, Grade, NPattern, Swing, ATR_PERIOD};
use crate::analyze::{indicators, scoring};

pub const FINE_MAX_A_BARS: usize = 16;
pub const FINE_MAX_B_BARS: usize = 12;
pub const LARGE_MAX_A_BARS: usize = 48;
pub const LARGE_MAX_B_BARS: usize = 32;

// a段内同向趋势K线的最低数量（放宽版趋势K判定）
pub const MIN_STRONG_A_LEG: usize = 1;
// 微型N判定：a段与b段幅度都很小
pub const SMALL_N_A_ATR: f64 = 3.0;
pub const SMALL_N_B_ATR: f64 = 1.0;
pub const SMALL_N_B_MIN_POINTS: f64 = 5.0;
// b段动能衰减判定：反向K线实体少于2根不判；后半段平均实体 <= 前半段75% 视为衰减。
// 用整体均值比而不是逐根比较，中间夹小阳/小阴不会破坏“整体变小”的判定。
const B_WEAKENING_MIN_BODIES: usize = 2;
const B_WEAKENING_RATIO_MAX: f64 = 0.75;
// b段深V判定：做多时内部低点低于 S2 的幅度超过 b 段净幅度一半，
// 视为“先大幅下跌再大幅拉回”的折返路径，而不是沿单一方向运动的健康回撤。
const B_V_SHAPE_REVERSAL_RATIO: f64 = 0.5;

/// a段内同向趋势K线根数（含 S0），用于校验a段是否具备实际推动
pub fn a_leg_strong_count(p: &NPattern, trend_k_relaxed: &[(bool, bool)]) -> usize {
    let mut count = 0;
    for i in p.s0.index..=p.s1.index {
        if p.dir == Dir::Down && trend_k_relaxed[i].1 {
            count += 1;
        }
        if p.dir == Dir::Up && trend_k_relaxed[i].0 {
            count += 1;
        }
    }
    count
}

/// 微型N：a段幅度 < 3倍ATR 且 b段幅度 < max(1倍ATR, 5点)，
/// 避免把"a段强趋势+b段小横盘"这类正常结构误判为小N
pub fn is_small_n(p: &NPattern, atr20: &[Option<f64>]) -> bool {
    let atr_s1 = atr20.get(p.s1.index).and_then(|x| *x).unwrap_or(1.0);
    let atr_s2 = atr20.get(p.s2.index).and_then(|x| *x).unwrap_or(1.0);
    let a_small = p.a_move < SMALL_N_A_ATR * atr_s1;
    let b_small = p.b_move < (SMALL_N_B_ATR * atr_s2).max(SMALL_N_B_MIN_POINTS);
    a_small && b_small
}

/// b段反向K线实体是否整体衰减。
/// 反向K线指与主趋势方向相反的回调K线：做多看阴线实体、做空看阳线实体。
pub(crate) fn b_leg_weakening(
    bars: &[Bar],
    start: usize,
    end: usize,
    dir: Dir,
) -> (bool, Option<f64>) {
    let mut bodies = Vec::new();
    for i in start + 1..=end {
        let body = match dir {
            Dir::Up => (bars[i].open - bars[i].close).max(0.0),
            Dir::Down => (bars[i].close - bars[i].open).max(0.0),
        };
        if body > 0.0 {
            bodies.push(body);
        }
    }
    if bodies.len() < B_WEAKENING_MIN_BODIES {
        return (false, None);
    }

    let mid = bodies.len() / 2;
    let first: f64 = bodies[..mid].iter().sum();
    let second: f64 = bodies[mid..].iter().sum();
    let first_mean = first / mid as f64;
    let second_mean = second / (bodies.len() - mid) as f64;
    if first_mean <= 0.0 {
        return (false, None);
    }
    let ratio = second_mean / first_mean;
    (ratio <= B_WEAKENING_RATIO_MAX, Some(ratio))
}

/// b段路径是否呈深V折返。
/// 做多时 S2 是回调端点，若 b 段内部出现过明显低于 S2 的低点，
/// 说明价格先反向走深再大幅拉回；做空同理看明显高于 S2 的高点。
fn b_leg_deep_reversal(
    bars: &[Bar],
    start: usize,
    end: usize,
    dir: Dir,
    s2_price: f64,
    b_move: f64,
) -> bool {
    if b_move <= 0.0 {
        return false;
    }
    let mut path_low = f64::INFINITY;
    let mut path_high = f64::NEG_INFINITY;
    for i in start + 1..=end {
        path_low = path_low.min(bars[i].low);
        path_high = path_high.max(bars[i].high);
    }
    let threshold = B_V_SHAPE_REVERSAL_RATIO * b_move;
    match dir {
        Dir::Up => path_low < s2_price - threshold,
        Dir::Down => path_high > s2_price + threshold,
    }
}

pub fn make_pattern(
    level: &'static str,
    dir: Dir,
    s0: Swing,
    s1: Swing,
    s2: Swing,
    bars: &[Bar],
    trend_k: &[(bool, bool)],
) -> Option<NPattern> {
    // A段K线根数含 S0 本身：S0 是转折极值K，同时也是新腿的第一根K。
    let a_bars = s1.index.saturating_sub(s0.index) + 1;
    let b_bars = s2.index.saturating_sub(s1.index);
    if a_bars < 3 || b_bars < 2 {
        return None;
    }

    let (a_move, b_move, retracement) = match dir {
        Dir::Down => {
            let a = s0.price - s1.price;
            let b = s2.price - s1.price;
            (a, b, if a > 0.0 { b / a } else { 0.0 })
        }
        Dir::Up => {
            let a = s1.price - s0.price;
            let b = s1.price - s2.price;
            (a, b, if a > 0.0 { b / a } else { 0.0 })
        }
    };

    if a_move <= 0.0 {
        return None;
    }

    let endpoint_failure = match dir {
        Dir::Down => s2.price >= s0.price,
        Dir::Up => s2.price <= s0.price,
    };

    // 做多 b 段中间任意低点触到或跌破 S0、做空任意高点触到或突破 S0，
    // 都按结构破位处理。只看端点会漏掉“先挖坑再收回”的 V 型路径。
    let path_failure = bars.get(s1.index + 1..=s2.index).is_some_and(|leg| {
        leg.iter().any(|b| match dir {
            Dir::Up => b.low <= s0.price,
            Dir::Down => b.high >= s0.price,
        })
    });

    let b_v_shape = b_leg_deep_reversal(bars, s1.index, s2.index, dir, s2.price, b_move);
    let hard_failure = endpoint_failure || path_failure || b_v_shape;

    let grade = if hard_failure {
        Grade::Invalid
    } else if retracement < 0.20 {
        Grade::TooShallow
    } else if retracement <= 0.50 {
        Grade::A
    } else if retracement <= 0.66 {
        Grade::B
    } else if retracement <= 0.80 {
        Grade::C
    } else {
        Grade::TooDeep
    };

    let mut a_strong_trend = 0;
    for i in s0.index..=s1.index {
        if dir == Dir::Down && trend_k[i].1 {
            a_strong_trend += 1;
        }
        if dir == Dir::Up && trend_k[i].0 {
            a_strong_trend += 1;
        }
    }

    let mut b_strong_reverse = 0;
    for i in s1.index + 1..=s2.index {
        if dir == Dir::Down && trend_k[i].0 {
            b_strong_reverse += 1;
        }
        if dir == Dir::Up && trend_k[i].1 {
            b_strong_reverse += 1;
        }
    }

    let (b_weakening, b_weakening_ratio) = b_leg_weakening(bars, s1.index, s2.index, dir);

    let a_speed = a_move / a_bars as f64;
    let b_speed = b_move / b_bars as f64;

    let mut c_move = 0.0;
    let mut c_bars = 0;
    if s2.index + 1 < bars.len() {
        c_bars = bars.len() - 1 - s2.index;
        c_move = match dir {
            Dir::Down => {
                s2.price
                    - bars[s2.index + 1..]
                        .iter()
                        .map(|b| b.low)
                        .fold(f64::INFINITY, f64::min)
            }
            Dir::Up => {
                bars[s2.index + 1..]
                    .iter()
                    .map(|b| b.high)
                    .fold(f64::NEG_INFINITY, f64::max)
                    - s2.price
            }
        };
    }

    let mut c_hard_failure = false;
    for i in s2.index + 1..bars.len() {
        let broken = match dir {
            Dir::Up => bars[i].low < s0.price,
            Dir::Down => bars[i].high > s0.price,
        };
        if broken {
            c_hard_failure = true;
            break;
        }
    }

    Some(NPattern {
        level,
        dir,
        s0,
        s1,
        s2,
        a_bars,
        b_bars,
        a_move,
        b_move,
        retracement,
        grade,
        hard_failure,
        a_too_long: a_bars > 7,
        b_too_long: match grade {
            Grade::A => b_bars > 8,
            Grade::B => b_bars > 12,
            Grade::C => b_bars > 14,
            _ => b_bars > 8,
        },
        b_fast: b_speed > 0.8 * a_speed,
        b_weakening,
        b_weakening_ratio,
        a_strong_trend,
        b_strong_reverse,
        c_move,
        c_bars,
        c_extended: c_move >= 1.2 * a_move,
        c_hard_failure,
    })
}

fn extreme_between(bars: &[Bar], start: usize, end: usize, want_high: bool) -> Option<Swing> {
    if start + 1 >= end {
        return None;
    }

    let mut best_index = start + 1;
    let mut best_price = if want_high {
        f64::NEG_INFINITY
    } else {
        f64::INFINITY
    };

    for i in start + 1..end {
        let price = if want_high { bars[i].high } else { bars[i].low };
        let better = if want_high {
            price > best_price
        } else {
            price < best_price
        };
        if better || (price == best_price && i > best_index) {
            best_index = i;
            best_price = price;
        }
    }

    Some(Swing {
        index: best_index,
        price: best_price,
        is_high: want_high,
    })
}

fn better_pattern(a: &NPattern, b: &NPattern) -> bool {
    let ra = a.grade.rank();
    let rb = b.grade.rank();
    if ra != rb {
        return ra > rb;
    }

    let qa = a.a_too_long as u8 + a.b_too_long as u8 + a.b_fast as u8;
    let qb = b.a_too_long as u8 + b.b_too_long as u8 + b.b_fast as u8;
    if qa != qb {
        return qa < qb;
    }

    let ta = a.a_bars + a.b_bars;
    let tb = b.a_bars + b.b_bars;
    if ta != tb {
        return ta < tb;
    }

    if a.s1.index != b.s1.index {
        return a.s1.index > b.s1.index;
    }
    if a.a_move != b.a_move {
        return a.a_move > b.a_move;
    }
    if a.s0.index != b.s0.index {
        return a.s0.index > b.s0.index;
    }
    false
}

pub(crate) fn best_pattern_for_b_end(
    level: &'static str,
    dir: Dir,
    b_end: Swing,
    bars: &[Bar],
    starts: &[Swing],
    trend_k: &[(bool, bool)],
    max_a_bars: usize,
    max_b_bars: usize,
) -> Option<NPattern> {
    let mut best: Option<NPattern> = None;
    let atr20 = indicators::atr(bars, ATR_PERIOD);

    for s0 in starts.iter().rev() {
        if s0.index >= b_end.index {
            continue;
        }
        if b_end.index - s0.index > max_a_bars + max_b_bars {
            break;
        }

        let anchor_ok = match dir {
            Dir::Down => s0.price > b_end.price,
            Dir::Up => s0.price < b_end.price,
        };
        if !anchor_ok {
            continue;
        }

        let Some(s1) = extreme_between(bars, s0.index, b_end.index, dir == Dir::Up) else {
            continue;
        };
        if s1.index - s0.index < 2 || b_end.index - s1.index < 2 {
            continue;
        }
        if s1.index - s0.index > max_a_bars || b_end.index - s1.index > max_b_bars {
            continue;
        }

        if let Some(p) = make_pattern(level, dir, *s0, s1, b_end, bars, trend_k) {
            let cur_score = scoring::score_a(bars, &atr20, &p) * 0.6 + scoring::score_b(&p) * 0.2;
            let best_score = best
                .as_ref()
                .map(|b| scoring::score_a(bars, &atr20, b) * 0.6 + scoring::score_b(b) * 0.2)
                .unwrap_or(f64::NEG_INFINITY);
            if best.as_ref().map_or(true, |b| {
                if p.hard_failure != b.hard_failure {
                    !p.hard_failure
                } else if cur_score > best_score + 1e-9 {
                    true
                } else if (cur_score - best_score).abs() <= 1e-9 {
                    better_pattern(&p, b)
                } else {
                    false
                }
            }) {
                best = Some(p);
            }
        }
    }

    best
}
```

```rust
/// a段质量分：衡量“推动腿”的幅度与K线质量，采用乘法短板结构。
///
/// 公式：
///   dim_a = 0.5 + 4.5 × 幅度因子 × 速度因子 × 干净因子 - 跳空扣分
///
/// 设计要点（避免“各项中等、凑满高分”的加法漏洞）：
/// 1. 幅度、速度、干净度三项相乘，任何一项弱都会按比例压低总分；
/// 2. 推进速度 = (净推进/根数)/ATR：0.25~0.55 满档，0.15 以下零分，
///    0.55 以上过快段降权，0.90 以上保留 0.6 下限；
/// 3. 干净因子由整条腿所有K参与，逐根按 K 线方向、实体大小、影线打分，
///    大反向K、逆势长影、大同色K直接扣分；普通小K给轻分，速度因子惩罚小K慢腿；
///    S1 最后一根固定权重 1，其余权重 = clamp(振幅/ATR, 0.25, 2.0)；
/// 4. 幅度因子带甜区：1.5~2.5 ATR 过渡，2.5 ATR 起满档，上限随
///    N_ATR（A+B 净幅度）浮动到 8+（N-12）×0.5，超过上限线性降到 0.6；
/// 5. A段内部大跳空按次数和超出 0.8 倍 ATR 的部分单独扣分，
///    向上、向下都统计，且不再参与幅度和速度收益。
pub(crate) fn score_a(bars: &[Bar], atr20: &[Option<f64>], p: &NPattern) -> f64 {
    let d = a_leg_detail(bars, atr20, p);
    if d.atr <= 0.0 {
        return 0.0;
    }
    let leg_atr = d.net_move / d.atr;
    let n_atr = (d.net_move + p.b_move) / d.atr;
    let amplitude = a_leg_amplitude_factor(leg_atr, n_atr);
    let speed_atr = d.net_move / p.a_bars.max(1) as f64 / d.atr;
    let speed = a_leg_speed_factor(speed_atr);
    a_leg_score_formula(amplitude, speed, d.q, d.gap_penalty)
}

/// A段干净因子（ATR 加权）：整条腿所有K都参与，逐根打质量分后做
/// “S1 权重 1、其余权重 = clamp(振幅/ATR, 0.25, 2.0)”加权平均。
/// 加权平均 -2~+1 映射到 0..1；没有有效K线时返回 0。
fn a_leg_clean_fit(bars: &[Bar], atr20: &[Option<f64>], p: &NPattern) -> f64 {
    let mut weight_sum = 0.0;
    let mut total_sum = 0.0;
    for i in p.s0.index..=p.s1.index {
        let Some(bar) = bars.get(i) else {
            continue;
        };
        let atr = atr20.get(i).copied().flatten();
        let (mut score, kind) = a_leg_bar_score_detail(bar, atr, p.dir);
        if i == p.s1.index && kind == ALegBarKind::ReverseWick {
            score -= A_LEG_BAR_REVERSE_WICK_ENDPOINT_EXTRA;
        }
        let weight = if i == p.s1.index {
            1.0
        } else {
            match atr {
                Some(a) if a > 0.0 => ((bar.high - bar.low) / a)
                    .clamp(A_LEG_BAR_WEIGHT_MIN_ATR, A_LEG_BAR_WEIGHT_MAX_ATR),
                _ => 1.0,
            }
        };
        weight_sum += weight;
        total_sum += score * weight;
    }
    if weight_sum > 0.0 {
        ((total_sum / weight_sum + A_LEG_CLEAN_SCORE_SHIFT) / A_LEG_CLEAN_SCORE_SCALE)
            .clamp(0.0, 1.0)
    } else {
        0.0
    }
}

/// 同色：干净 +1.0、普通同色 +0.6、大同色 -0.6、逆势长影 -0.5；
/// 反向：顺向长影 +0.2、小反向 -0.4、普通反向 -1.2、大反向 -1.8、
/// 逆势长影 -0.9；十字星 -0.1；无效K记 0。

/// 单根K线质量分，同时返回干净度归类。
fn a_leg_bar_score_detail(bar: &Bar, atr: Option<f64>, dir: Dir) -> (f64, ALegBarKind) {
    let Some(atr) = atr else {
        return (0.0, ALegBarKind::Neutral);
    };
    if atr <= 0.0 {
        return (0.0, ALegBarKind::Neutral);
    }
    let range = bar.high - bar.low;
    if range <= 0.0 {
        return (0.0, ALegBarKind::Neutral);
    }
    let body = (bar.close - bar.open).abs();
    let upper = bar.high - bar.open.max(bar.close);
    let lower = bar.open.min(bar.close) - bar.low;
    let body_ratio = body / range;
    let pos = match dir {
        Dir::Up => (bar.close - bar.low) / range,
        Dir::Down => (bar.high - bar.close) / range,
    };
    let same = match dir {
        Dir::Up => bar.close > bar.open,
        Dir::Down => bar.close < bar.open,
    };
    let oppose_wick = match dir {
        Dir::Up => upper,
        Dir::Down => lower,
    };
    let favor_wick = match dir {
        Dir::Up => lower,
        Dir::Down => upper,
    };
    let favorable_close = match dir {
        Dir::Up => pos <= 0.30,
        Dir::Down => pos >= 0.70,
    };

    // 反向K带顺向长影（做多下影/做空上影）且收盘有利：拒绝/供应信号，给温和正分。
    // 这类K先于反向大小实体判断，避免把“好影线”误伤成大反向。
    if !same
        && range >= A_LEG_BAR_REVERSE_RANGE_ATR_MIN * atr
        && favor_wick >= A_LEG_FAV_WICK_BODY_RATIO * body
        && favorable_close
    {
        return (A_LEG_BAR_FAVORABLE_WICK, ALegBarKind::FavWick);
    }

    // 逆势长影优先于 Doji、小反向和大实体分类：小实体长影不会再被吞掉。
    if oppose_wick >= A_LEG_WICK_ATR_MIN * atr && oppose_wick >= A_LEG_WICK_BODY_RATIO * body {
        if !same
            && (body >= A_LEG_BAR_BIG_REVERSE_BODY_ATR_MIN * atr
                || range >= A_LEG_BAR_BIG_REVERSE_RANGE_ATR_MIN * atr)
        {
            return (A_LEG_BAR_BIG_REVERSE, ALegBarKind::BigReverse);
        }
        if same && range > A_LEG_BAR_BIG_SAME_ATR_MIN * atr {
            return (A_LEG_BAR_BIG_SAME, ALegBarKind::BigSame);
        }
        if same {
            return (A_LEG_BAR_WICK, ALegBarKind::Wick);
        }
        return (A_LEG_BAR_REVERSE_WICK, ALegBarKind::ReverseWick);
    }

    if body <= 0.0 || body_ratio < A_LEG_DOJI_BODY_RATIO_MAX {
        return (A_LEG_BAR_DOJI, ALegBarKind::Doji);
    }

    if same {
        if range > A_LEG_BAR_BIG_SAME_ATR_MIN * atr {
            return (A_LEG_BAR_BIG_SAME, ALegBarKind::BigSame);
        }
        if body_ratio >= A_LEG_CLEAN_BODY_RATIO_MIN
            && oppose_wick <= A_LEG_CLEAN_WICK_BODY_RATIO_MAX * body
            && range >= A_LEG_CLEAN_RANGE_ATR_MIN * atr
            && range <= A_LEG_CLEAN_RANGE_ATR_MAX * atr
        {
            return (A_LEG_BAR_CLEAN, ALegBarKind::Clean);
        }
        return (A_LEG_BAR_PLAIN_SAME, ALegBarKind::PlainSame);
    }

    if body >= A_LEG_BAR_BIG_REVERSE_BODY_ATR_MIN * atr
        || range >= A_LEG_BAR_BIG_REVERSE_RANGE_ATR_MIN * atr
    {
        return (A_LEG_BAR_BIG_REVERSE, ALegBarKind::BigReverse);
    }
    if body >= A_LEG_BAR_REVERSE_BODY_ATR_MIN * atr
        || range >= A_LEG_BAR_REVERSE_RANGE_ATR_MIN * atr
    {
        return (A_LEG_BAR_REVERSE, ALegBarKind::Reverse);
    }
    (A_LEG_BAR_SMALL_REVERSE, ALegBarKind::SmallReverse)
}

/// A段大跳空信息：返回（缺口合计、跳空根数、扣分）。
/// 单根缺口低于 0.8 倍 ATR 视为可接受的正常波动，不参与扣分。
fn a_leg_gap_info(bars: &[Bar], p: &NPattern, atr: f64) -> (f64, usize, f64) {
    if atr <= 0.0 || p.a_move <= 0.0 {
        return (0.0, 0, 0.0);
    }
    let mut gap_sum = 0.0;
    let mut gap_count = 0usize;
    let mut excess_atr = 0.0;
    for i in p.s0.index + 1..=p.s1.index {
        let Some(prev) = bars.get(i.saturating_sub(1)) else {
            continue;
        };
        let Some(cur) = bars.get(i) else {
            continue;
        };
        if prev.rollover || cur.rollover {
            continue;
        }
        let gap_up = (cur.low - prev.high).max(0.0);
        let gap_down = (prev.low - cur.high).max(0.0);
        let gap = gap_up.max(gap_down);
        if gap >= A_LEG_GAP_MIN_ATR * atr {
            gap_sum += gap;
            gap_count += 1;
            excess_atr += (gap / atr - A_LEG_GAP_MIN_ATR).max(0.0);
        }
    }
    let penalty = (gap_count as f64 * A_LEG_GAP_PENALTY_PER_GAP
        + excess_atr * A_LEG_GAP_PENALTY_PER_EXCESS_ATR)
        .min(A_LEG_GAP_PENALTY_MAX);
    (gap_sum, gap_count, penalty)
}

/// a段质量分的纯公式（抽出便于单测与标定）：三个因子相乘后扣跳空。
fn a_leg_score_formula(amplitude: f64, speed: f64, clean: f64, gap_penalty: f64) -> f64 {
    clamp(0.5 + A_LEG_CORE_SCORE_WEIGHT * amplitude * speed * clean - gap_penalty)
}

/// 幅度因子：1.5 ATR 以下线性升温，2.5 ATR 起满档；
/// 上限随形态尺度 N_ATR 浮动，超过上限后线性衰减到 0.6。
fn a_leg_amplitude_factor(leg_atr: f64, n_atr: f64) -> f64 {
    if leg_atr < A_LEG_AMPLITUDE_ATR_RAMP_MIN {
        return leg_atr / A_LEG_AMPLITUDE_ATR_RAMP_MIN;
    }
    if leg_atr < A_LEG_AMPLITUDE_ATR_FULL_MIN {
        return 0.5
            + 0.5 * (leg_atr - A_LEG_AMPLITUDE_ATR_RAMP_MIN)
                / (A_LEG_AMPLITUDE_ATR_FULL_MIN - A_LEG_AMPLITUDE_ATR_RAMP_MIN);
    }
    let cap = A_LEG_AMPLITUDE_CAP_BASE_ATR
        + (n_atr - A_LEG_AMPLITUDE_CAP_N_BASE_ATR).max(0.0) * A_LEG_AMPLITUDE_CAP_PER_N_ATR;
    if leg_atr <= cap {
        return 1.0;
    }
    if leg_atr <= cap + A_LEG_AMPLITUDE_CAP_DECAY_ATR {
        return 1.0
            - (leg_atr - cap) / A_LEG_AMPLITUDE_CAP_DECAY_ATR * A_LEG_AMPLITUDE_CAP_DECAY_MAX;
    }
    A_LEG_AMPLITUDE_FLOOR
}

/// 速度因子：0.15 以下零分，0.25~0.55 满档，
/// 0.55~0.90 过快段线性降权，0.90 以上保留 0.6。
fn a_leg_speed_factor(speed_atr: f64) -> f64 {
    if speed_atr < A_LEG_SPEED_ATR_MIN {
        return 0.0;
    }
    if speed_atr < A_LEG_SPEED_ATR_RAMP_FULL {
        return (speed_atr - A_LEG_SPEED_ATR_MIN)
            / (A_LEG_SPEED_ATR_RAMP_FULL - A_LEG_SPEED_ATR_MIN);
    }
    if speed_atr <= A_LEG_SPEED_ATR_FULL {
        return 1.0;
    }
    if speed_atr <= A_LEG_SPEED_ATR_FAST_START {
        return 1.0
            - (speed_atr - A_LEG_SPEED_ATR_FULL)
                / (A_LEG_SPEED_ATR_FAST_START - A_LEG_SPEED_ATR_FULL)
                * A_LEG_SPEED_FAST_PENALTY_MAX;
    }
    A_LEG_SPEED_FLOOR
}

pub(crate) fn score_b(p: &NPattern) -> f64 {
    let mut s = p.grade.score_base();
    if p.b_fast && p.grade != Grade::C {
        s -= 0.5;
    }
    if p.b_too_long {
        s -= 0.5;
    }
    // b段反向K线整体收敛：回调动能在衰减，对反转结构是加分项。
    // 但长b本身已扣过动能消耗分，不能再用“后半段变小”补回来。
    if p.b_weakening && !p.b_too_long {
        s += 0.3;
    }
    // 反向强K扣分：健康回撤里第一根反向强K是正常的，不惩罚；
    // 从第 2 根起每根扣 0.3（至多按 2 根计），避免把正常回撤误判为弱结构。
    s -= (p.b_strong_reverse.saturating_sub(1).min(2) as f64) * 0.3;
    clamp(s)
}

pub(crate) fn strong_opposite_body_at(
    bars: &[Bar],
    atr20: &[Option<f64>],
    dir: Dir,
    index: usize,
) -> Option<f64> {
    let bar = bars.get(index)?;
    let atr = atr_at(atr20, index);
    if atr <= 0.0 {
        return None;
    }
    let range = bar.high - bar.low;
    let body = (bar.close - bar.open).abs();
    if range <= 0.0 || body <= 0.0 {
        return None;
    }

    let (dir_ok, close_ok) = match dir {
        Dir::Up => {
            let bearish = bar.close < bar.open;
            let close_near_low = bar.close - bar.low <= 0.5 * body;
            (bearish, close_near_low)
        }
        Dir::Down => {
            let bullish = bar.close > bar.open;
            let close_near_high = bar.high - bar.close <= 0.5 * body;
            (bullish, close_near_high)
        }
    };

    if dir_ok
        && close_ok
        && range >= OPPOSING_PREV_RANGE_ATR_MIN * atr
        && body >= OPPOSING_PREV_BODY_ATR_MIN * atr
        && body >= 0.5 * range
    {
        Some(body)
    } else {
        None
    }
}

fn entry_block_flags(
    bars: &[Bar],
    atr20: &[Option<f64>],
    dir: Dir,
    trigger: usize,
) -> (bool, bool) {
    let atr = atr_at(atr20, trigger);
    let wick_block = bars.get(trigger).is_some_and(|b| {
        if atr <= 0.0 {
            return false;
        }
        let range = b.high - b.low;
        if range <= 0.0 {
            return false;
        }
        let body = (b.close - b.open).abs();
        let upper = b.high - b.open.max(b.close);
        let lower = b.open.min(b.close) - b.low;
        let wick = match dir {
            Dir::Up => upper,
            Dir::Down => lower,
        };
        wick > body
            && wick >= ENTRY_BLOCK_WICK_ATR_MIN * atr
            && wick >= ENTRY_BLOCK_WICK_RANGE_MIN * range
    });

    let prev_block =
        trigger > 0 && strong_opposite_body_at(bars, atr20, dir, trigger - 1).is_some();

    (wick_block, prev_block)
}

/// 预警K线长影线硬门槛（2026-08-15）：做多看下影、做空看上影。
/// 七条同时满足才算长影线预警，任何一条不满足都不产生 wick 信号。
/// `prev` 是预警K线前面的 b 向K线；缺失或振幅不足都算不通过。
pub(crate) fn is_wick_warning_bar(bar: &Bar, atr: f64, dir: Dir, prev: Option<&Bar>) -> bool {
    let range = bar.high - bar.low;
    if range <= 0.0 || atr <= 0.0 {
        return false;
    }
    let body = (bar.close - bar.open).abs();
    if body <= 0.0 {
        return false;
    }
    let upper = bar.high - bar.open.max(bar.close);
    let lower = bar.open.min(bar.close) - bar.low;
    let wick = match dir {
        Dir::Up => lower,
        Dir::Down => upper,
    };
    let reverse_shadow = match dir {
        Dir::Up => upper,
        Dir::Down => lower,
    };
    let close_ok = match dir {
        Dir::Up => (bar.high - bar.close) / range <= WICK_CLOSE_POS_MAX,
        Dir::Down => (bar.close - bar.low) / range <= WICK_CLOSE_POS_MAX,
    };
    wick >= WICK_BODY_RATIO_MIN * body
        && wick >= WICK_RANGE_MIN * range
        && wick >= WICK_ATR_MIN * atr
        && close_ok
        && reverse_shadow <= WICK_REVERSE_SHADOW_MAX_RATIO * range
        && prev
            .map(|p| wick >= WICK_PREV_BAR_RANGE_MIN * (p.high - p.low))
            .unwrap_or(false)
}

/// 长影线收盘方向契合度：做多长下影收阴、做空长上影收阳时轻微扣分。
/// 识别阶段仍允许这类K线成为 wick 预警，只是质量分略低。
pub(crate) fn wick_direction_penalty(bar: &Bar, dir: Dir) -> f64 {
    match dir {
        Dir::Up if bar.close < bar.open => WICK_DIRECTION_PENALTY,
        Dir::Down if bar.close > bar.open => WICK_DIRECTION_PENALTY,
        _ => 0.0,
    }
}

/// 预警K线体量扣分：按振幅相对 ATR20 的倍数衡量是否“特别巨大”，方向无关。
pub(crate) fn warning_size_penalty(bars: &[Bar], atr20: &[Option<f64>], w: usize) -> f64 {
    let Some(bar) = bars.get(w) else {
        return 0.0;
    };
    let atr = atr_at(atr20, w);
    if atr <= 0.0 {
        return 0.0;
    }
    let ratio = (bar.high - bar.low) / atr;
    if ratio <= WARNING_SIZE_ATR_START {
        return 0.0;
    }
    let t = ((ratio - WARNING_SIZE_ATR_START) / (WARNING_SIZE_ATR_FULL - WARNING_SIZE_ATR_START))
        .clamp(0.0, 1.0);
    WARNING_SIZE_PENALTY_MAX * t
}

fn warning_base(kind: &str) -> f64 {
    match kind {
        // engulf 仅保留给历史落盘记录，新识别统一为 strong。
        "strong" | "engulf" | "wick" => 3.5,
        "cumulative" => 3.0,
        _ => 2.0,
    }

/// 预警K线质量分：强反转/长影线基准 3.5，多K累积覆盖基准 3.0，
/// 再扣除长影线收盘方向与预警K线体量扣分。
pub(crate) fn dim_warning(
    bars: &[Bar],
    atr20: &[Option<f64>],
    w: usize,
    kind: &str,
    dir: Dir,
) -> f64 {
    let direction_penalty = if kind == "wick" {
        bars.get(w)
            .map(|bar| wick_direction_penalty(bar, dir))
            .unwrap_or(0.0)
    } else {
        0.0
    };
    clamp(warning_base(kind) - direction_penalty - warning_size_penalty(bars, atr20, w))
}

/// 入场分 = 0.60×A段 + 0.20×B段 + 0.20×预警K线。
/// 多K累积覆盖总分封顶 3.9，只允许小仓试错；
/// 长影线预警总分封顶 3.0，历史分档胜率全面偏弱，不进 3.5+ 标准仓区间。
pub(crate) fn entry_score(dim_a: f64, dim_b: f64, dim_warning: f64, kind: &str) -> f64 {
    let score = 0.60 * dim_a + 0.20 * dim_b + 0.20 * dim_warning;
    match kind {
        "cumulative" => score.min(CUMULATIVE_ENTRY_SCORE_MAX),
        "wick" => score.min(WICK_ENTRY_SCORE_MAX),
        _ => score,
    }
}

/// 单根K线构成的反转形态：只有干净吞没判为强反转，反向长影线单独识别。
/// 强趋势K不再单独作为 strong：用户口径是“强反转必须吞没前一根K线，
/// 没吞没说明强度不够”，SA0 1154 这类无吞没的强趋势K只作为 b 段锚点，
/// 不再直接产生预警。
pub(crate) fn single_reversal_pattern(
    bars: &[Bar],
    atr20: &[Option<f64>],
    dir: Dir,
    w: usize,
    run_start: usize,
) -> Option<SingleReversalKind> {
    let Some(bar) = bars.get(w) else {
        return None;
    };
    let range = bar.high - bar.low;
    if range <= 0.0 {
        return None;
    }

    // 阴包阳/阳包阴：仅对反转段的第一根反向K线检查，目标实体是它前面的b向K线。
    // 要求前面是b向实体（做空为阳线、做多为阴线），新K线为反向收盘并包住前一根实体，
    // 且至少一侧严格超过前实体——避免"实体完全相同的镜像小K线"被误判为吞没。
    // 2026-08-16：strong 只保留干净吞没，反向影线必须严格小于 50% 振幅。
    let engulf = w == run_start
        && w > 0
        && match dir {
            Dir::Up => {
                let prev = &bars[w - 1];
                prev.close <= prev.open
                    && bar.close > bar.open
                    && bar.close >= prev.open
                    && bar.open <= prev.close
                    && (bar.close > prev.open || bar.open < prev.close)
            }
            Dir::Down => {
                let prev = &bars[w - 1];
                prev.close >= prev.open
                    && bar.close < bar.open
                    && bar.open >= prev.close
                    && bar.close <= prev.open
                    && (bar.open > prev.close || bar.close < prev.open)
            }
        };
    let reverse_shadow = match dir {
        Dir::Up => bar.high - bar.open.max(bar.close),
        Dir::Down => bar.open.min(bar.close) - bar.low,
    };
    let body = (bar.close - bar.open).abs();
    let atr = atr_at(atr20, w);
    if engulf
        && reverse_shadow < STRONG_REVERSE_SHADOW_MAX_RATIO * range
        && body >= STRONG_ENGULF_BODY_ATR_MIN * atr
    {
        return Some(SingleReversalKind::Strong);
    }

    is_wick_warning_bar(bar, atr, dir, bars.get(w.saturating_sub(1)))
        .then_some(SingleReversalKind::Wick)
}

/// 多K累积覆盖：连续反向收盘至少2根，且最后一根收盘越过强b向K线的开盘价（吞没其实体）
pub(crate) fn cumulative_coverage(
    bars: &[Bar],
    run_start: usize,
    j: usize,
    anchor_open: f64,
    dir: Dir,
) -> bool {
    if j < run_start + 1 {
        return false;
    }
    let last_close = bars[j].close;
    match dir {
        Dir::Up => last_close > anchor_open,
        Dir::Down => last_close < anchor_open,
    }
}
```

```rust
    pub trend_bonus: f64,
}

fn is_opposite_close(bar: &Bar, dir: Dir) -> bool {
    match dir {
        Dir::Up => bar.close > bar.open,
        Dir::Down => bar.close < bar.open,
    }
}

fn anchor_is_strong(
    bars: &[Bar],
    atr20: &[Option<f64>],
    trend_k: &[(bool, bool)],
    dir: Dir,
    anchor: usize,
) -> bool {
    scoring::strong_b_dir_trend_candle(trend_k, anchor, dir)
        || scoring::strong_opposite_body_at(bars, atr20, dir, anchor).is_some()
}

/// Detect the warning kind for the current bar.  Only already-closed bars are
/// used; cumulative needs at least one preceding opposite-close bar so the
/// current bar can complete the run.
fn warning_kind_at(
    bars: &[Bar],
    atr20: &[Option<f64>],
    trend_k: &[(bool, bool)],
    p: &NPattern,
    w: usize,
) -> Option<&'static str> {
    if let Some(kind) = scoring::single_reversal_pattern(bars, atr20, p.dir, w, w) {
        return Some(kind.as_str());
    }
    if !is_opposite_close(&bars[w], p.dir) || w == 0 {
        return None;
    }

    let mut run_start = w;
    while run_start > p.s1.index + 1 && is_opposite_close(&bars[run_start - 1], p.dir) {
        run_start -= 1;
    }
    let anchor = run_start - 1;
    let anchor_strong = anchor_is_strong(bars, atr20, trend_k, p.dir, anchor);
    let strict_confirm = matches!(p.grade, Grade::B | Grade::C);

    if w > run_start
        && (anchor_strong || strict_confirm)
        && scoring::cumulative_coverage(bars, run_start, w, bars[anchor].open, p.dir)
    {
        return Some("cumulative");
    }
    None
}

fn pattern_for_current_bar(
    level: &'static str,
    dir: Dir,
    bars: &[Bar],
    starts: &[Swing],
    trend_k: &[(bool, bool)],
    w: usize,
    max_a_bars: usize,
    max_b_bars: usize,
) -> Option<NPattern> {
    let b_end = Swing {
        index: w,
        price: if dir == Dir::Up {
            bars[w].low
        } else {
            bars[w].high
        },
        is_high: dir == Dir::Down,
    };
    pattern::best_pattern_for_b_end(
        level, dir, b_end, bars, starts, trend_k, max_a_bars, max_b_bars,
    )
}

fn candidate_for(
    bars: &[Bar],
    atr20: &[Option<f64>],
    trend_k: &[(bool, bool)],
    trend_k_relaxed: &[(bool, bool)],
    p: &NPattern,
    w: usize,
    tick: f64,
) -> Option<WarningCandidate> {
    if !matches!(p.grade, Grade::A | Grade::B | Grade::C)
        || pattern::is_small_n(p, atr20)
        || pattern::a_leg_strong_count(p, trend_k_relaxed) < pattern::MIN_STRONG_A_LEG
        || crate::analyze::pattern_window_has_rollover_until(bars, p, w)
    {
        return None;
    }
    let kind = warning_kind_at(bars, atr20, trend_k, p, w)?;

    let dim_a = scoring::score_a(bars, atr20, p);
    let dim_b = scoring::score_b(p);
    let dim_warning = scoring::dim_warning(bars, atr20, w, kind, p.dir);
    let entry_score = scoring::entry_score(dim_a, dim_b, dim_warning, kind);

    let buffer = (0.1 * scoring::atr_at(atr20, w)).max(1.0);
    let (entry, stop) = match p.dir {
        Dir::Up => (bars[w].high + tick, p.s2.price - buffer),
        Dir::Down => (bars[w].low - tick, p.s2.price + buffer),
    };
    let target = p.s1.price;
    let risk = (stop - entry).abs();
    let space = match p.dir {
        Dir::Up => target - entry,
        Dir::Down => entry - target,
    };
    if risk <= 0.0 || space <= 0.0 {
        return None;
    }

    let trend = indicators::analyze_60m(&bars[..=w.min(bars.len().saturating_sub(1))]);
    Some(WarningCandidate {
        direction: p.dir,
        grade: p.grade.label().to_string(),
        level: p.level,
        s0_index: p.s0.index,
        s1_index: p.s1.index,
        s2_index: p.s2.index,
        a_move: p.a_move,
        b_move: p.b_move,
        a_bars: p.a_bars,
        b_bars: p.b_bars,
        retracement: p.retracement,
        warning_index: w,
        warning_kind: kind,
        entry_score,
        dim_a,
        dim_b,
        dim_warning,
        entry,
        stop,
        target,
        risk,
        rr: space / risk,
        trend_state: trend.direction.clone(),
        trend_bonus: 0.0,
    })
}

/// Forward-only replay.  Every truncation ends at an already-closed bar, so no
/// event references a future bar.  For each warning bar only the best-scoring
/// AB candidate is returned.
pub fn replay_warnings(symbol: &str, bars: &[Bar], tick: f64) -> Vec<WarningCandidate> {
    let mut best_by_warning: std::collections::HashMap<(Dir, usize), WarningCandidate> =
        std::collections::HashMap::new();

    for w in 0..bars.len() {
        let prefix = &bars[..=w];
        if prefix.len() < ATR_PERIOD + 2 {
            continue;
        }
        let atr20 = indicators::atr(prefix, ATR_PERIOD);
        let trend_k = indicators::trend_flags(prefix, &atr20);
        let trend_k_relaxed = indicators::trend_flags_relaxed(prefix, &atr20);
        let swings_fine = indicators::find_swings(prefix, &atr20, 2, 8);
        let swings_large = indicators::find_swings(prefix, &atr20, 5, 10);

        let mut patterns: Vec<NPattern> = Vec::new();
        for dir in [Dir::Up, Dir::Down] {
            let starts = if dir == Dir::Up {
                swings_fine
                    .iter()
                    .filter(|s| !s.is_high)
                    .copied()
                    .collect::<Vec<_>>()
            } else {
                swings_fine
                    .iter()
                    .filter(|s| s.is_high)
                    .copied()
                    .collect::<Vec<_>>()
            };
            if let Some(p) = pattern_for_current_bar(
                "fine",
                dir,
                prefix,
                &starts,
                &trend_k,
                w,
                pattern::FINE_MAX_A_BARS,
                pattern::FINE_MAX_B_BARS,
            ) {
                patterns.push(p);
            }

            let starts = if dir == Dir::Up {
                swings_large
                    .iter()
                    .filter(|s| !s.is_high)
                    .copied()
                    .collect::<Vec<_>>()
            } else {
                swings_large
                    .iter()
                    .filter(|s| s.is_high)
                    .copied()
                    .collect::<Vec<_>>()
            };
            if let Some(p) = pattern_for_current_bar(
                "large",
                dir,
                prefix,
                &starts,
                &trend_k,
                w,
                pattern::LARGE_MAX_A_BARS,
                pattern::LARGE_MAX_B_BARS,
            ) {
                patterns.push(p);
            }
        }

        for p in patterns {
            if let Some(c) = candidate_for(prefix, &atr20, &trend_k, &trend_k_relaxed, &p, w, tick)
            {
                let key = (c.direction, c.warning_index);
                match best_by_warning.get(&key) {
                    Some(existing) if existing.entry_score >= c.entry_score => {}
                    _ => {
                        best_by_warning.insert(key, c);
                    }
                }
            }
        }
    }

    let _ = symbol;
    let mut out: Vec<WarningCandidate> = best_by_warning.into_values().collect();
    out.sort_by(|a, b| {
        a.warning_index.cmp(&b.warning_index).then_with(|| {
            let au = matches!(a.direction, Dir::Up);
            let bu = matches!(b.direction, Dir::Up);
            bu.cmp(&au)
        })
    });
    out
}
```

### D.8 已知换月窗口检查

来源：`crates/n-core/src/analyze/mod.rs`，原始第323～341行。

```rust
/// 形态结构窗口内是否跨过换月 bar。
/// 前向识别口径：只看 s0 到预警K线（含）之间，绝不引用预警之后的K线。
pub(crate) fn pattern_window_has_rollover_until(
    bars: &[Bar],
    p: &NPattern,
    warning_index: usize,
) -> bool {
    let Some(start) = bars.get(p.s0.index) else {
        return false;
    };
    if start.rollover {
        return true;
    }
    let end = warning_index.min(bars.len().saturating_sub(1));
    if p.s0.index > end {
        return false;
    }
    bars[p.s0.index..=end].iter().any(|b| b.rollover)
}
```
