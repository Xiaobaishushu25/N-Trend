# P3 单手止盈最低 1R

后续变更：两手目标也已扩展为近目标修正，见[2026-11-17 P3近目标修正.md](2026-11-17%20P3近目标修正.md)。下文保留原单手补丁说明，其中“两手恢复原生S1”的行为已由后续补丁替代。

仅调整 P3 的单手止盈：实际开仓只成交一手时，原生 S1 的有利方向空间不足或等于初始风险 1R，执行止盈目标外推至 1R；经过原生 S1 不触发止盈。原生 S1 远于 1R 时，仍以 S1 止盈。固定模式与分批追踪模式均适用。

1R 按实际成交均价与原始结构止损的距离计算，不含手续费，且不随移动止损重新定义。目标触发后仍由执行器报单，实际成交收益可能受价格跳变、费用和滑点影响。止损、无跟随、超时和强制退出规则保持有效，1R 不是最低保证收益。

条件单、冻结信号证据与风险预算快照保留原生 S1，准入净盈亏比也仍按原生 S1 计算。实际持仓与成交历史中的目标价记录执行目标；到达 1R 目标的单手出场归因为 `target_1r`，较远的 S1 出场仍为 `target_s1`。

实际开成两手时，原有 S1 止盈规则不变。两手开仓分两次成交时，第一手暂按单手目标执行，第二手成交后按新的成交均价重算风险，并恢复原生 S1 目标。两手分批止盈后剩下的一手继续按保本与追踪规则管理，不会再次按单手入场规则外推目标。

本改动通过成交后的目标调整接口生效；已建立且不再有开仓成交的旧持仓不会自动重写目标，历史交易不会回写。本地代码变更不等于服务器已部署。

回归验证覆盖多空镜像、两种出场模式、S1 小于/等于/大于 1R、成交滑点后的 1R、重启恢复、分笔开仓从一手变两手、双手分批后的余仓保护，以及原始止损继续有效。
