# 交易结构与回撤参数第二轮研究

本轮承接评分参数研究，冻结正式评分与权重；仅扩展离线研究。所有行情仍是已经查看过的开发资料，不能重新命名为未见验证。

## 修正内容

之前的子项消融在本折结束时冻结了结果，并把每折存在任何未决结果作为否决条件，造成后续已经结束的跨月订单仍被永久计作未完成。本轮明确分离两个时间：

- 预警所属区间决定本折接纳哪些候选。
- 事后观察截止时间决定这些候选可看到的最终退出结果。

模型训练与内层选模默认仍严格按当时截止时间，仅用已经结束的交易；只有外层事后消融显式允许追踪至原研究末日。观察末日已知的最后一分钟收盘可以计入外层结果，训练截止不因此放宽。

截止时尚未可见的退出价格、平仓成交、最高有利运行、平仓费用和盈亏会在as-of标签中隐藏。真正同分钟路径歧义、缺失行情和研究尾部仓位仍保留未知，不填零。

参数证据增加已定价部分覆盖检查与39项探索的BH调整。积极结果只能标为已定价子集上的暂定信息价值；不再使用“任意未决即所有参数无效”的规则，也不将未知盈亏假设为可控的固定金额。

## 冻结的对照

|交易因素|版本|
|---|---|
|止盈|净200元 / S1|
|无跟随|第5根保留 / 关闭|
|计划损失上限|200元 / 500元|

共8组，每组独立回放每侧1/2tick与同品种订单占用。200元上限用于筛选下单前已经知道的计划风险，不移动结构止损，跳空后的实际损失不保证受上限约束。

本轮固定v1综合分≥70，不重新优化总分门槛或权重；全部可用历史用于初始化既有订单/持仓。报告同时列全窗口与初始训练之后的区间，主表采用后者。因准入门槛、时间覆盖不同，不能将本轮固定≥70的金额直接与第一轮滚动前20%汇总作同口径比较。

无跟随退出另作同入场反事实：比较原无跟随退出样本在取消规则后能否转好，分别列独立路径与原策略实际接纳样本。退出变化会影响后续占用，故主策略比较仍须完整重放，不能将路径差额直接视为账户改善。

## B回撤与不交易

B专门模型的交易过程固定为净200元、第5根无跟随、计划上限500元。四个事先登记的模型为：全量原始特征线性岭、删除回撤比例、只让回撤比例具有样条映射、回撤样条加A幅度/效率交互。惩罚固定为10，不再搜索赢家参数。

每个模型比较两种准入：过去合格预警预测分布的前20%门槛，以及预测净元严格>0。预测分数不修改正式形态评分，且仍以v1≥70限定研究交易范围；样本不足不能训练时不接新单。每折只预测新预警，旧订单及持仓跨折继续。

不交易基线为零笔、零收益；空交易集合不判定为盈利候选。报告列预测金额分箱与实现金额，防止将模型的正预测当成已证明正期望。

A×B条件格只使用实际观察的特征组合、训练期边界及后续已知结果，保留样本量，不人为构造相互不一致的A/B指标。39项参数的修正消融沿用第一轮固定惩罚与rank20研究设定，和本轮v1≥70的B专门准入是两个不同问题。

## 入口

参数：`scripts/factor-study-followup-v1.json`。新入口支持`replay`、`evaluate`、`reassess`、`report`、`run`，所有输出均要求新目录，旧报告保持不变。

```powershell
python -X utf8 scripts/research_factor_study_followup.py run --input research-runs/factor-study-20261031/long-replay-v1 --diagnosis research-runs/factor-study-20261031/long-diagnose-v1 --out research-runs/factor-followup-20261031/REPRO-LONG-NEW
python -X utf8 scripts/research_factor_study_followup.py run --input research-runs/factor-study-20261031/three-month-replay-v1 --diagnosis research-runs/factor-study-20261031/three-month-diagnose-v3 --out research-runs/factor-followup-20261031/REPRO-RECENT-NEW
```

取消无跟随的两种目标只生成一次独立路径；200/500元准入复用相同路径，随后分别重放订单占用。新路径逐笔通过金额/R与独立源分钟行情、费用检查。模型最后训练退出时间必须早于预测折开始。

## 产物

正式运行根目录为`research-runs/factor-followup-20261031/long-v1`及`three-month-v1`：

- `replay`：关闭无跟随的独立路径、源行情/费用核验。
- `evaluate`：8组及B模型的全部订单账本、预测、模型、校准与条件格、汇总。
- `reassess`：修正后的全量消融、参数证据、跨折结果补齐数量。
- `report/report.md`：综合报告与39项参数证据表。

阶段冻结输入、源代码、协议和输出哈希。来源费率快照与历史合约映射原时点可知性的限制沿用上一轮，不能据开发诊断直接上线。
