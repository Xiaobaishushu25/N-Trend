# 预警K线体量扣分调整（2026-08-16）

## 背景

复盘 SR0 1172 时发现，预警K线实体只有 4 点、振幅 6 点，ATR20 约 7.45，
大小健康，但旧口径按“实体覆盖到 S1 目标空间的比例”扣了 0.5 分。

旧口径的问题在于把“覆盖到目标空间”当成缺陷。实际很多结构本身就有破位预期，
预警K线已经推进到目标附近并不代表K线过大；真正需要压制的对象是特别巨大的预警K线，
因为它会消耗较多动能，并把入场极值推远、拉大止损空间。

## 变更

`warning_space_overrun_penalty` 改为 `warning_size_penalty`，扣分只看预警K线振幅
相对 ATR20 的倍数，不再看实体与剩余目标空间的比例。

```text
振幅 / ATR20 <= 2.0  不扣分
2.0 - 3.5            线性扣 0 - 1.0
>= 3.5               扣满 1.0
```

扣分方向无关，做多、做空共用同一公式。该扣分只降 `dim_warning`，不取消预警识别。

## 影响

SR0 1172 的预警K线振幅约 `0.81 × ATR20`，低于扣分起点，`dim_warning` 从 3.0 回到 3.5，
综合评分从 `2.3167` 升到 `2.4167`。

按全库 779 条有预警K线的历史信号统计，振幅达到 2 倍 ATR20 的约占 3.3%，
新扣分只影响“特别巨大”的尾部预警K线。

## 兼容与记录

- 旧落盘记录不回填，历史评分、dims 与统计结果保持不变。
- 新扫描、新评估或复盘重算产生的信号使用新口径。
