# 空头中继 / 横盘破位形态优化（待办记录）

> 记录时间：2026-08-14
> 状态：仅记录思路，暂不实施

## 背景

复盘 SS0 2026-08-13 晚至 2026-08-14 早盘走势时发现：

- 08-13 21:15 高点 14420，随后快速下跌，22:15 附近最低约 14300；
- 之后至 08-14 01:00 在 14300-14355 窄幅横盘；
- 08-14 09:30 收于 14300，09:45 强阴线收于 14255，向下破位；
- 60 分钟方向为弱下跌，属于空头背景。

人工判断：这段结构应视为“空头中继 / 新一轮下跌起点”，而不是等价格反弹形成经典 N 后再做空。

## 当前系统复核结果

- 09:45、09:50 的扫描没有给 SS0 输出关注信号；
- 60 分钟方向识别为弱下跌，空头背景本身成立；
- 当时已有较老的精细/较大做空 N 信号，但预警和触发在 08-13 21:15、22:00 前后已经发生，到 08-14 09:30 已过时，决策点空间反转，评分归零；
- 当前箱体逻辑也没有识别这段横盘：
  - 区间高度约 55 点，而箱体要求高度 >= 3 倍 ATR；按当时 ATR20 约 24 点计算，需要约 72 点以上；
  - 按当前摆动识别口径，上轨有 08-13 23:15 的 14355、08-14 01:00 的 14335 两次确认，但下轨在破位前只有 08-13 22:15 的 14300 一次确认，不满足上下轨各至少 2 次触碰；
  - 箱体做空预警要求某根K线高点到上轨 0.4 倍 ATR 以内，且本身为强阴线或长上影；横盘期间多为中性小实体K线，破位K线发生位置已在下沿以下，不能同时兼任预警。

## 后续优化方向

1. 不硬套 N 形态或现有箱体，单独识别“空头中继 / 横盘破位”：
   - A 段下跌：幅度建议 >= 3 倍 ATR，且下跌段有趋势K线；
   - 60 分钟方向偏空；
   - 横盘区：至少 8 根 15 分钟K线，上下沿有反复确认；
   - 触发：收盘价跌破横盘下沿，最好由强阴线完成。
2. 单独设计入场、止损、决策点：
   - 入场：破位K线收盘价下方；
   - 止损：横盘上沿上方或破位K线高点上方；
   - 决策点/目标：先以前低或横盘高度等幅测算。
3. 不建议通过降低现有箱体阈值来硬接这种形态，避免把普通窄幅整理全部识别成破位。

## 回测验证计划

- 用 15 分钟K线在历史品种上统计该形态的触发次数、胜率、平均 R、盈亏比；
- 重点比较横盘高度 < 3 倍 ATR 的窄横盘，与 >= 3 倍 ATR 的标准箱体，破位后的表现差异；
- 验证 60 分钟偏空背景是否明显提升胜率；
- 如果统计结果支持，再实现为独立信号类型并接入 2.0 分析管线。
