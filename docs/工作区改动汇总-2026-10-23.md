# 工作区改动汇总：多策略账户与 P2/P3

提交分支：`codex/multi-strategy-accounts`。本次合并工作区中已有的多策略框架、候选策略实现、研究复现工具及相关客户端改动。

## 交易运行框架

- 增加策略注册、入场计划、退出与仓位模块、冻结版本、事件分发和持久化状态；保留原 `n_pattern` / `n_exit_v1` / `n_score_v1`。
- 引入独立账户和策略实例，账户之间隔离委托、成交、配置、凭据、模拟资金及恢复状态。
- 增加本地模拟账本和账户对比接口、增量推送与客户端实例选择；旧交易接口继续指向默认实例。
- 支持客户端创建和重连独立 SimNow 账户，展示认证、结算和同步状态，账户凭据只保存在服务器。

## P2/P3

- P2 使用原 S1，P3 按真实成交价计算最多 2R 的较近目标；均固定一手和原结构止损。
- 增加预警时费用、净空间、ATR14 过滤，以及触发后下一条行情、拟成交价复核、同品种槽位和拒单终止处理。
- 增加完整 15 分钟桶、5/60 桶退出、长假和周末退出、未知委托恢复及诊断快照。
- 交易页提供对应方案预设，冻结费用和日历版本。参考日历覆盖至 2026-10-31；部署不会自动创建或启用 P2/P3 实例。

## 信号系统与升级

- 统一正常客户端与服务端入口，移除独立研究启动身份、运行配置及相关配对脚本，保留离线研究、归档与重建工具。
- 旧信号库升级保留原始行情、设备、配置和真实成交事实，归档旧信号依据，并保留信号 ID 序列。
- 增加显式带持仓迁移模式：要求柜台新鲜持仓快照、账户身份及持仓数量完全对应，拒绝未核实委托；原策略、配置、持仓保护、部分退出状态、历史和去重记录继续保留。
- 带持仓迁移不自动平仓；未入场条件单需先撤销。设置执行预警起始时间，防止重建的历史信号变成新入场。

## 研究与复现

- 新增信号搜索、优化、消融和实盘执行审计 Rust 入口。
- 补齐费用重估、资金容量、统一一手、开仓价值、盈亏分布、品种广度、休市规则和服务器记录对比脚本。
- 保存冻结研究协议、费用与日历参考快照、候选策略完整规格及结果说明；运行数据、数据库、归档、凭据和构建输出不随本次提交发布。

## 验证

- Rust 核心库、服务端、协议测试及新增带持仓恢复回归测试通过；研究可执行入口一并编译。
- 桌面 Rust 客户端 `cargo check --offline -p n-trend-analyzer` 通过。
- Python 测试 111 项完成，其中 7 项按既有环境条件跳过；CTP 桥接测试 16 项通过。
- 前端 Node 测试 40 项通过，TypeScript 检查与生产构建通过。
