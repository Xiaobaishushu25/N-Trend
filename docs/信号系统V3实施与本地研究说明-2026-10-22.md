# 信号系统 V3：实施与本地研究说明

日期：2026-10-22。分支 `codex/signal-system-v3`，基线提交 `ae0ad5f`。原 `feat/mobile` 工作区未切换或清理。未部署生产服务。

## 本地环境

在此分支工作目录运行：

```powershell
npm run server:research
# 在另一个终端配对独立客户端：
python scripts/pair_research_client.py
npm run dev:research
```

服务固定监听 `127.0.0.1:18081`，开发前端使用 `127.0.0.1:5174`，开发客户端标识为 `com.ntrend.app.research`。它的凭据目录、系统密钥环及单实例身份独立于正式客户端。本地配对密钥位于 `data-dev/research-pairing-key.txt`，只在本机读取并在开发客户端设置中配对，不上传Git。

研究模式必须显式指定已准备的数据目录；不读取生产配置或交易状态，不启动行情/交易桥和后台交易任务，禁止交易/应急交易/外部取数接口。客户端也禁止直接回退到本机8766交易桥。

## 数据归档与升级

已通过现有只读备份接口下载服务器一致性快照。原始输入位于 `research-archives/server-20261022-v3/`，工作副本为 `data-dev/ntrend.db`。归档包含数据库、用户批注/决策及独立交易历史/执行快照导出。它不是运行目录，不受客户端日常轮换备份管理。

归档原始5分钟行情82,149根，22个品种，覆盖2026-07-03 09:35至2026-10-22 11:25。旧信号2,904条、旧预测10,012条。清理后原始行情逐行SHA256保持一致：`8c56bb3f6ad82bab8d3048dc5b831cb2e2380c93721d0b518e4ca2f586cf0a51`。

```powershell
python scripts/prepare_signal_v3.py --auth-file <正式客户端凭据文件> --archive-dir research-archives/<新归档目录> --data-dir <全新开发数据目录>
```

输出目录必须全新，重复调用不会覆盖现有工作库。旧信号、预测、模型、模拟结局和信号批注/决策只在归档保留；原始行情、合约元数据和换月信息保留。信号ID序列不重置，避免旧交易编号指向新信号。

未来正式升级使用 `scripts/migrate_signal_v3.py --data-dir <生产数据目录> --archive-dir <独立归档目录>`。仅在服务已停止且无活动条件单、未对账委托、托管持仓或退出任务的维护窗口运行；脚本不会停止服务、撤单或平仓。它保留生产设备与配置、真实交易记录及原信号依据，清除旧影子比较。失败标记会阻止新版服务启动，必须先检查归档恢复情况。**本次没有执行生产迁移。**

## 回放、标签与模型

识别算法和人工入场评分公式保留。换月标记进入识别及特征截断，缺失和未完成K线不得伪装成已知行情。旧阶梯回放和触发收盘模型已移除。

共享规则由纯价格策略驱动，实盘仍由柜台成交回报确认持仓：小仓1R退出；大仓首手1R成交后保本，剩余仓位1.6R激活、回撤0.8R跟踪及S1退出。报价触发不等于实际成交。15分钟复盘明确使用较粗分辨率；研究用5分钟回放，路径不明单列歧义，不提供确定训练标签。

预警确认时冻结快照和预测，只使用A/B段、速度、回撤、预警量比、形态分与方向。禁止使用未来触发收盘、完整成交量和持仓结果。冻结后的输入与概率只追加，不补写伪实时预测。历史重建与前瞻来源分开保存。

```powershell
cargo run -p n-core --bin signal-research -- --db=data-dev/ntrend.db --train --out=research-runs/<全新批次>
```

每个批次保存信号、数据集、OOF预测、配置、成本口径、滚动指标和报告。冻结当前执行参数，不改变真实仓位或风控。模型训练与报告使用按标签结束时间隔离的滚动验证、同品种非重叠机会；固定小仓退出与实际评分分档分别报告，并使用相同预测做配对2跳压力比较。

**默认往返2.5 tick额外费用是明确的研究代理，不是真实逐日交易所手续费；连续合约尚不能替代具体合约成交验证。** 1/2跳不利滑点已反映在模拟价格中，不再重复扣除。毛R和净R分别保存，分批交易按全部退出累计收益生成净标签。

所有当前历史均属于开发诊断，不能冒充独立前瞻验证。模型初始为challenger，不自动晋升；日常卡片只展示通过资格检查的前瞻预测，否则显示“暂无经验证概率”。首次前瞻评审至少30交易日、200个非重叠机会组，并要求AUC区间、Brier、1/2跳增量、回撤与真实合约/成本证据通过。现阶段不满足这些条件。

## 风控与验收边界

现有 `min_entry_risk_ticks`、大小仓手数和风险配置保持原值。日内亏损熔断当前被注释停用；`max_risk_percent`尚需执行层审计。本次没有启用500元上限、改变隔夜规则或宣称实际亏损有硬上限。
