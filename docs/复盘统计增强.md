# 复盘统计增强

> 版本：`SIM_VERSION = 8`（2026-08-10）
> 范围：只扩展复盘统计与诊断落库，本轮不改评分权重、不改交易和出场规则。
> 补充（2026-08-11）：K线图右侧形态卡新增追价深度展示；触发量能“放量确认”阈值由 ≥1.3 改为 ≥2.0，形态卡与复盘口径一致。

## 背景

复盘页已经具备 `signal_outcomes` 闭环：信号落库 → 按简化规则回放结局 → 按维度分组统计。过去主要看胜率和平均 R，平均 R 为 +0.18 时无法区分“赢的次数少”还是“赢的幅度小”，也看不到盈亏漏在哪个环节。本轮把有区分度潜力的特征落成可筛选、可分组、可交叉验证的统计维度，为下一轮校准评分和持仓规则提供证据。

## 一、已实现

### 1. 模拟与落库：新增 5 个诊断字段

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `target_tier` | 止盈层级 | 按止盈出场时记录 `tp1` / `tp2`，其他出场为空 |
| `b_vol_ratio` | b段缩量比 | b段均量 ÷ a段均量（15m），a/b 段共用 s1 那根 K 线，均只统计成交量 > 0 的 K 线 |
| `a_move_atr` | a段强度 | a段幅度 ÷ 触发 bar 的 ATR20，ATR 缺失记空 |
| `trigger_lag_bars` | 预警延迟 | 预警 K 线到触发 K 线的根数差 |
| `trigger_overshoot_r` | 追价深度 | 做多取 `(触发bar high - entry) / risk`，做空取 `(entry - 触发bar low) / risk` |

这些字段由 `outcome::annotate` 在回放时计算，随结局一起写入 `signal_outcomes`。

### 2. 统计指标扩展

- R 分布：`avg_win_r`、`avg_loss_r`、`payoff`（盈亏比）、`profit_factor`（盈利因子）、`r_ge1_rate`、`r_ge2_rate`。
- MFE/MAE 条件分布：`mfe_ge1_rate`（已结算样本中 MFE 达到 1R 的比例）、`mae_le_neg1_rate`、以及这两类样本的平均 R（`avg_r_mfe_ge1`、`avg_r_mae_le_neg1`）。用于回答“方向对了为什么没赚到”和“方向错了为什么没及时走”。
- 目标层级：`ext_target_n`（扩展目标数，落库目标位 R > 1）、`tp1_exits`、`tp2_exits`、`tp2_conversion`（TP2 ÷ 扩展目标数）、`tp2_of_ext_rate`（TP2 ÷ 全部止盈出场）。用于验证扩展止盈是否真的贡献了额外 R。
- 净 R 估算：`avg_net_r = avg(r_multiple - 2.5 × tick / risk)`，tick 取 `symbols.effective_tick`，只用于复盘展示，不改变成交模拟。

### 3. 分组维度：新增 16 个

| 维度 | 分桶 | 想验证的问题 |
| --- | --- | --- |
| 出场原因 | 止盈 / 止损 / 无跟随 / 时间退出 / 换月 / 其他 | 盈亏漏在哪个出场环节 |
| 放量分桶 | <0.8 / 0.8-1.0 / 1.0-1.3 / 1.3-2.0 / ≥2.0 | 放量区分度是否单调，避免把衰竭当确认 |
| b段缩量 | <0.8 / 0.8-1.0 / 1.0-1.3 / ≥1.3 | 回调缩量是否提高胜率 |
| 回撤率 | <20% / 20-33% / 33-50% / 50-66% / >66% | 找最优回撤区间，替代 A/B/C 级粗分 |
| b/a速度比 | <0.5 / 0.5-0.8 / 0.8-1.2 / ≥1.2 | `(b_move/b_bars) ÷ (a_move/a_bars)` 的最优比例 |
| a段强度 | <3 / 3-6 / 6-10 / ≥10 | 强腿 vs 弱腿的真实区分度 |
| 预警延迟 | 1 / 2-3 / 4-6 / 7-12 / >12 根 | 即时触发与延迟触发的胜率差异 |
| 追价深度 | <0.1 / 0.1-0.3 / 0.3-0.6 / ≥0.6 R | 验证“禁止追价”纪律的实际代价 |
| 止盈层级 | TP2扩展止盈 / TP1止盈 / 其他 | 扩展止盈的贡献 |
| 跳空成交 | 入场跳空 / 出场跳空 / 双跳空 / 无跳空 | 跳空对结果的影响 |
| 评分六个分项 | 每个均按 <2.0 / 2.0-3.5 / ≥3.5 | 从 `detail.dims[0..6]` 解析，定位评分项里哪些真正有区分度 |

原有维度（评分段、等级、方向、级别、小时、品种、量能确认、持仓量、60m趋势分、组合维度）全部保留。

### 4. 明细表新增列

`target_tier`、`b_vol_ratio`、`b/a速度`（b_move ÷ a_move）、`根数比`（b_bars ÷ a_bars）、`trigger_lag_bars`、`trigger_overshoot_r`、`a_move_atr`、`net_r`。

### 5. 存储迁移与结果重算

- 通过现有幂等 `ensure_column` 为 `signal_outcomes` 增加 5 个诊断列，老库可重复升级。
- `SIM_VERSION` 从 7 升到 8，旧版本结局打开复盘页时自动进入重算。
- 同结构跨扫描只保留首条、未触发不计胜率、同根 K 线双触按止损等既有口径不变。

### 6. 统计口径

- 所有比率分母为“已结算且对应字段有值”的样本；`profit_factor` 在亏损总额为 0 时返回空，避免除零。
- b段缩量比使用闭区间 `s0..=s1` 与 `s1..=s2`，s1 那根 K 线两边都参与，避免漏掉节点量能。
- 净 R 按固定 `2.5 tick/往返` 估算，后续可升级为按品种配置的佣金/滑点/点差模型。
- 当前样本量较小，任一桶少于 20-30 个实例只作参考，不据此自动生成交易规则。

## 二、下轮计划

按对“胜率和盈亏比优化”的直接影响排序：

1. **多空分开处理**：当前做多胜率 59.2%、PF 1.83，做空胜率 36.1%、PF 0.68；即使评分 ≥3.5，做空仍然 PF 0.81。下一轮应把方向和评分拆成两套评估口径，先验证“做空提高阈值”或“做空单独调参”是否稳定，再做统一规则。
2. **触发前特征交叉验证进评分**：放量 ≥2.0、回撤率、b/a速度比都是触发前已知的特征，且当前分桶有初步区分度。先在多空分层里验证单调性和稳定性，再考虑进评分权重。
3. **时间维度**：持仓根数、夜盘/日盘、星期几。当前 22:00 时段表现较好、10:00 较弱，先看隔夜与时段是否系统性改变胜率，再决定是否加时段过滤。
4. **信号疲劳度**：同品种近期已出现信号数。连续触发容易扎堆在趋势末端，验证信号“新鲜度”是否影响后续表现。
5. **品种/板块分层**：按品种和板块分组，控制不同品种波动率与流动性的干扰，防止少数品种主导结论。
6. **可配置成本模型**：按品种配置佣金、滑点、点差，把净 R 从固定估算升级为可落库、可对比的真实口径。
7. **暂缓项**：市场状态分层、持仓量连续化、c段破位回放、信号序列依赖。这些方向有价值，但依赖更多前置数据或更复杂的状态建模，本轮不实现。

完整数据结论见 [复盘统计报告](复盘统计报告.md)。
