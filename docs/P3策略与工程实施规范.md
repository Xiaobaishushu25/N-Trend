# P3 策略与工程实施规范

日期：2026-11-13。根据本轮用户决定整理。P3 只指金额预算与 S1/分批追踪方案；删除已废弃的固定一手、2R 封顶候选实现，不保留其运行兼容分支。

## 一、P3 全策略

### 信号与准入

沿用现有 N 结构预警源和稳定信号键；策略自身不修改信号形成算法。预警只使用当时已完成数据；ATR14 使用完成的 15m K 线计算，5m 是原始数据输入粒度，不是持仓计时粒度。

| 项目 | 冻结规则 |
|---|---|
| 评分 | score >= 2.5 |
| 结构风险 | 多空方向化距离严格为正；至少 10 ticks |
| 摩擦 | 双边各 1 tick + 账户保守往返手续费，不超过结构价格风险金额的 20% |
| ATR | 0.75 <= risk/ATR14 <= 2.5；缺失或无效 ATR 拒绝 |
| 净 RR | 用结构 S1 目标；扣两侧预计滑点和手续费后 >= 1.0 |
| 合约 | 绑定真实月份合约，核对 tick、点值、费用与会话日历；采用保守交割月规避规则 |
| 重复/竞争 | 相同信号只受理一次；保留同品种互斥与未知委托占用 |

所有价格、评分、费用和比率输入必须 finite；tick、点值和 ATR 必须为正。不能把元数据或费率缺失解释为零成本。

### 金额预算

整笔计划预算 B=600 元，最多两手。设方向 d 为多头 +1、空头 -1，点值为 M，tick 为 t：

`预计入场 = entry + d*t`

`预计止损成交 = stop - d*t`

`L1 = d*(预计入场 - 预计止损成交)*M + 保守往返手续费`

`N = min(2, floor(B/L1))`

L1<=300 开两手，300<L1<=600 开一手，L1>600 正常拒绝，不创建委托、不暂停实例。边界使用统一货币/价格精度判断，不能用放宽预算的 epsilon 硬塞一手。

报单前按真实拟报限价重算 L1、净 RR 与风险预留。手数只允许相对批准计划下调，不因盘口改善自动追加。已有成交和仍可能成交的在途委托必须同时计入；实际成交后继续核验并保留预算超额记录。

600 元是正常成交假设下的预算。按用户决定，本轮不启用日内亏损熔断，也不新增未经确定的账户总风险硬门槛；记录总持仓风险、未知委托和保证金状态，不将价格保本当成释放未知风险的理由。

### 等待与入场

1. 等待突破最多 12 个有效 15m 桶；不以墙钟时间填入午休或夜间休市桶。
2. 等待期间先触结构止损，永久作废该信号；先检查作废，再检查突破。
3. 使用真实合约新鲜盘口，以带价格上限/下限的可成交限价报单，并保留现有防追价限制。
4. 从首次报单开始计时，3 秒未全成则请求撤销剩余量；该时限是撤单请求目标，不是成交或撤单终态保证。撤单重试不重置首次报单截止时间。
5. 超时后本信号不重新追单、不补回剩余手数。只成交一手就保护这一手；开仓终态确认后按实际一手规则管理。
6. 委托结果未知时保留槽位和风险，核对柜台，不盲目重报。保护已成交仓位不能被未完成开仓的状态阻塞。

### 模式 A：S1 固定退出，首选研究基准

无论实际一手还是两手，全部在原结构 S1 退出；结构止损不放宽。先触止损、会话强平、时间退出等更高优先级事件时，不能继续等待 S1。

### 模式 B：首手 S1，余仓追踪

仅在实际已经成交两手、开仓剩余量不再可能增加时采用分批模式。实际只成一手使用模式 A。到 S1 时若开仓仍未结束，先终止剩余开仓意图，保护并退出已成交数量，不为凑齐两手继续追买。

首手 S1 退出只申请一手。只有确认这笔特定 S1 平仓累计成交一手后，才完成首手转换；不能用任意平仓回报或“价格碰过 S1”替代。立即清理完成的部分退出任务，保留余仓的止损、计时和追踪更新。

以真实成交均价 F 为成本，固定初始结构价格风险 `R0=d*(F-S)>0`。开仓结束后冻结 R0；止损推到 F 后不能把 R0 改为零。两手部分成交不同价时保留成交明细与加权均价。

第一版使用 F 作为价格保本线，不称作净费用保本。移动到预计净保本价留作单独实验，避免未经验证就额外改变退出概率。

统一多空计算：

`r = d*(last-F)/R0`

`peak_r = max(previous_peak_r, r)`

首手成交确认后允许保本；同时 peak_r>=1.6 时允许追踪：

`candidate_stop = F + d*(peak_r-0.8)*R0`

多头保护价只升不降，空头只降不升。按真实 tick 做方向化价格对齐。若保护更新生效时最新盘口已经越过新保护价，立即产生退出意图，不能假设曾在该保护价成交。峰值只能来自实际持仓之后的已观察行情。

F、R0、峰值、首手退出任务和累计成交、保护价、模式均持久化。重新启动不得把已确认首手状态重置，也不得补造历史追踪成交。

### 时间与会话保护

- 无跟随：前五个实际观察且完成的 15m 持仓桶，区间最大浮盈 MFE<0.5R 退出；检查一次。曾到0.5R后回撤，不因检查时浮盈低于0.5R而退出。迟到检查只取前五桶，不吸收后续桶的浮盈。
- 最大持仓：60 个有效 15m 桶。
- 周末：按真实合约、北京时间最后有效会话，收盘前10分钟同时禁入并发出全平意图。夜盘跨午夜时使用周六真实收盘时刻，不能拿柜台归属交易日的星期来判断。
- 节假日：使用明确冻结的 last_close/reopen；没有夜盘时不能等一个不存在的夜盘收盘。支持禁入与清仓时间相同。已存在的其他策略冻结节前窗口不在本轮被静默改写。
- 合约到期：按实际交易日避开交割月；在交割月前最后有效日盘收盘前10分钟禁入并请求全平，跨月夜盘不能按墙钟月份误放行。可通过 `entry_cutoffs` 为实际合约配置更早的禁入时刻。此保守规则不等同于逐交易所、品种、账户身份的完整交割资格审核；更早的限制需明确配置。
- 日历覆盖到期：覆盖结束前10分钟禁入并请求全平；不能靠未知的未来交易日继续持仓。
- 超过截止时间仍未成交的退出任务保留，不能到周一自动当作完成。

### 公共执行地基：已完成

| 项目 | 实施要求 |
|---|---|
| 零手拒绝 | 明确正常 Skip/Reject 结果；不创建条件单，不触发策略错误或暂停 |
| 报单前定仓 | 拟报限价重算风险和数量；计入已成交、在途、撤单未知的预留 |
| 入场截止 | 独立首次报单截止时间；超时撤剩余，不改价补回，不与平仓重试共用结束条件 |
| 部分成交保护 | 开仓等待与持仓保护分开；已有一手立即受止损保护，不能等两手全成 |
| 部分退出完成 | 通用任务完成转换；按任务累计成交确认，不依赖策略名称、评分档位或旧 reason 特判 |
| 止损抢占 | 高优先级全平可升级S1任务；取消在途止盈，按剩余持仓与被委托冻结的平仓量决定可再报量，防止重复平仓 |
| 迟到成交 | 已停止开仓后仍收到成交，追加到必须退出的数量；未确认委托不提前释放槽位 |
| 幂等与恢复 | 成交去重、委托终态与成交补齐核对；状态和结果原子持久化；重启恢复R0、峰值和首手状态 |

以上公共执行机制已实现，并通过离线柜台回归。报单风控接口区分拟报限价与实际成交阶段，提供累计开仓量、成交价乘手数与实际合约报价；只允许减少已批准数量。风控模块在实际成交后异常时保留成交、暂停新增风险并锁定退出，不回滚实际持仓。

唯一P3实现已注册为 `n_p3_v1`，配套 `risk_budget_v1` 仓位模块与 `p3_exit_v1` 退出模块，拒绝交叉误配。复用现有N预警源和公共执行地基；默认600元、最多两手、模式A，模式B为同一策略的可选参数。前端已接入新建预设、预算、最大手数、模式选择与过滤原因；P3首次报单撤单时限固定为3秒。没有部署或连接实盘，日内熔断保持停用。工程行为通过不代表策略收益已验证。工程详情见[执行状态机工程修复](2026-11-13%20执行状态机工程修复.md)，本轮实现见[P3策略实现与离线验证](P3策略实现与离线验证.md)。
