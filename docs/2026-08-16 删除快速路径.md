# 删除快速路径预警（2026-08-16）

## 结论

快速路径（`fast`）预警从本次起彻底删除：不再作为预警K线类型生成，旧落盘的
`fast` 记录会在下一次扫描或复盘刷新时物理清理，重建复盘数据时也会一并消失。

## 数据依据

按删除前的复盘口径统计：

| 指标 | fast | cumulative |
| --- | --- | --- |
| 信号数 | 405 | 169 |
| 已结算 | 284 | - |
| 胜率 | 44.0% | 48.6% |
| 平均 R | -0.055 | +0.095 |
| 盈亏因子 | 0.93 | 1.18 |

快速路径胜率低于“不做单也有约 50%”的基线，平均 R 为负、盈亏因子小于 1，
说明这条路径没有提供正向信息优势。多K累计覆盖（`cumulative`）并不差，
因此保留，只删除 `fast`。

## 行为变更

- `warning_base` 不再包含 `"fast" => 2.5`。
- 前向重放不再在 A 级浅回调场景把“首根反向收盘位置合格”的普通小K线当预警。
- 单根弱反向K线（含小实体吞没、长反向影线）不再单独放行；预警只来自
  `strong`（干净吞没）/ `wick`，以及 B/C 级或强锚场景的多K累计覆盖 `cumulative`。
- 强趋势K不再单独作为 `strong` 预警：没有吞没的强趋势K只作为 B 段锚点，
  A 级弱K线继续等干净吞没或长影线。
- 强反转与吞没合并为 `strong` 后，影线质量门槛继续生效：反向影线必须严格
  小于 50% 振幅，长反向影线不再被快速路径兜底。

## 历史数据处理

- 旧 `fast` 记录在下一次扫描或复盘刷新时按 `warning_kind = "fast"` 物理删除。
- 重建复盘数据会先清空事件表，历史 `fast` 自然不会再出现。
- 界面与邮件里的“快速路径/快速反转”文案仅保留给尚未清理的历史记录。

## 关联变更

- 删除 `fast_path_close_ok` 评分路径，A 级普通反向K线不再有独立放行分支。
- 相关测试改为验证“弱阳线不再预警，直到干净吞没出现才出 `strong`”。
