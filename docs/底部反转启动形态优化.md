# 底部反转启动形态优化（待办记录）

> 记录时间：2026-08-12
> 状态：仅记录思路，暂不实施

## 背景

复盘 JD0#4541 时发现：部分结构被识别成 N 形态，但 A 段幅度很小，
并不具备 N 形态所要求的“强动能 + 健康回调”前提。

JD0#4541 的实测参数：

- A 段：4 根 K 线，3801 -> 3847，幅度 46 点
- S1 处 ATR20 约 18，A 段幅度约 2.56 倍 ATR
- B 段：38 点，回撤率 82.6%，评级为“回撤过深”
- A 段质量分仅 1.075/5，综合分 1.30，系统标注“放弃本次结构”

结论：这种“A 段特别小”的形态不应被当作强动能 N 形态。

## 现象描述

价格经历一段下跌后，不出现新低，转为横盘；随后出现强趋势阳线、
长下影阳线等启动信号时，可以考虑做多。

这类形态更像“横盘/底部反转启动”，而不是经典 N 形态，也不是严格
意义的双底（两个低点未必接近）。当前系统仍会把它识别成 N 并落库，
导致低质量信号混入列表。

## 后续优化方向

1. 为 N 形态增加硬性门槛：A 段幅度不足 N 倍 ATR（参考值 3 倍 ATR，
   ATR 取 S1 处）时，直接不识别为 N。
2. 对“A 段过小但出现反向强 K / 长下影、且前低没有被跌破”的走势，
   单独识别为“横盘/底部反转启动”类型：
   - 不套用 N 形态的评分和入场框架
   - 单独设计入场、止损、决策点规则（例如以前低为决策点、
     以箱体低点为止损）
3. 后续用复盘统计验证该形态的胜率和盈亏比，再决定是否进入正式信号。

## 当前决定

- 本文仅作为待办记录，供后续优化使用
- 暂不改动识别逻辑和评分逻辑
