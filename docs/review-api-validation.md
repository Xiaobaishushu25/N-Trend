验证日期：2026-11-01；发布版本3.0.3。未连接生产服务、交易账户或运行生产历史重建。测试使用内存SQLite与隔离临时文件；当前工作区 ntrend.db 的 pattern_events 为0条。

## 性能验收

执行：

```text
cargo test -p n-core --lib benchmark_10000_precomputed_signals --release --offline -- --ignored --nocapture
```

Windows，rustc 1.97.0-nightly (64a965e90 2026-05-11)，release优化构建，内存SQLite。

| 项目 | 实测 |
|---|---:|
| 信号摘要 | 10,000条 |
| 每次实际匹配并参与总览/分类 | 10,000条，含缺评分样本 |
| 对应持有记录 | 180,000条 |

| 首屏gzip | 25,515 bytes |

查询计划：`SCAN r USING INDEX idx_review_current_warning`。只扫描当前摘要投影，不读取历史版本、生命周期或18万条持有明细。统计和查询快照固定同一结果集合。

计时包含服务层数据库读取、JSON摘要解析、筛选后去重选择、总览/默认分组/累计曲线计算、快照装配；不包含HTTP往返和gzip编码。gzip实测对完整首屏JSON压缩；HTTP测试另外验证实际响应的 Content-Encoding、认证及返回契约。

达到计划目标：预计算后的服务层查询P95≤500ms，默认首屏gzip≤200KiB。此为构造数据的本地验证，不代表生产硬件、磁盘数据库、多用户并发或首次历史回放耗时。

## 行为覆盖

- 固定一手首次1R全平，多空镜像，跳空止损，2 tick滑点与0.5 tick费用仅计一次。
- 原始事件不变；同根冲突为ambiguous；入场前/退出后极值不冒充确定持有极值。
- 缺5分钟行情、缺日历、未知乘数、换月、入场准入过滤均单独标记。
- 等待12根、无跟随5根、时间退出60根按15分钟交易K计数；午休不计数，周五跨午夜日历正常。
- 持久待处理队列随原始写入事务回滚；后台分批结果不提前可见；中断恢复与相同输入幂等。
- 已发布版本、查询快照与历史详情可独立读取；设备隔离、过期、分页、相同分数排序稳定。
- 品种/评分/时段组合、跨午夜多个时段、退出原因、定制分桶及其重叠校验；列表与统计样本一致。
- HTTP版本及权限校验、真实gzip响应、新接口请求类型、桌面命令注册和旧接口契约。
