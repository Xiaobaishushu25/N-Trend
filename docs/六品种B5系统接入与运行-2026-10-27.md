# 六品种 B5：系统接入与运行

实现日期：2026-10-27，北京时间。

已注册独立策略 `n_b5_six:1`，页面预置名为 **六品种 B5 · EG / PP / PVC / JD / SR / CJ**。固定品种代码为 EG0、PP0、V0、JD0、SR0、CJ0；每次开仓固定一手。选择依据是既有固定六品种18个月已有覆盖的主场景结果：B5约22,864.29元，B2约21,335.53元；没有重新按新结果筛选名单或优化参数。

## 在系统里运行

1. 更新并重启承载策略的 `n-headless` 服务端，然后打开更新后的客户端。策略目录来自服务端，单独更新客户端不会让旧服务端多出新算法。
2. 进入交易页，选择“新建”或现有实例的“配置”，在策略预置／策略模块中选择“六品种 B5”。可以使用独立本地模拟账户或 SimNow 账户。
3. 创建预置采用半自动模式、固定一手、最少10 tick风险、报单额外滑点0 tick。新实例默认暂停，核对账户和参数后手动启用。若希望系统自动报单，可在实例配置里选择全自动模式。
4. 本地模拟账户仍需填写实际月份合约的乘数、保证金和费用；交易月份随主力切换，因此也要补充新主力合约。策略中的冻结费率用于机会判断，模拟账户费率用于模拟账本，两者用途不同。
5. 启动／切换新版本时先建立历史预警去重状态，不补开历史交易。等待新的15分钟预警；条件池会显示已接受计划及被过滤信号的具体原因。

系统没有自动创建账户、切换现有实例、登录柜台或启用交易。源代码和构建产物可供用户按以上步骤运行。

## 实现规则

- 细摆点窗口2、大摆点窗口5，均不合并相近摆点；在原有结构资格中选择最近合格S0，同样的优先级也用于细／大级候选之间的选择。
- 评分至少2.5，A排除S0柱后的方向净实体大于0。
- 原预警突破入场；原S2加缓冲止损；价格按不利方向对齐tick。
- 目标取预警前12根完整15分钟柱中的合格严格确认转折，不能跨会话确认；无合适目标回S1，目标不超过S1，不增加2R封顶。
- 最少10 tick风险、计划往返摩擦不超过0.2R、计划成本／毛目标空间不超过10%、计划和拟成交价分别通过净盈亏比至少1的守卫；不增加原P2/P3的风险／ATR区间过滤。
- 小时顺向或缺失使用原触价；小时非空且≤0，非累积覆盖预警等待一分钟收盘确认。小时≤−1，长休市前最后10分钟停止新增入场，完整观察分钟收盘仍毛浮亏的持仓在后续行情发出退出。
- 同品种一个已触发占用；仅小时不顺向类别限制同组同向最多2个占用。六品种中EG／PP／PVC为一组，JD／SR／CJ为另一组；顺向或小时信息缺失不占新增类别名额。
- 同A身份为品种、方向、S0时间、S1时间。只有实际接纳且已经完成的原stop退出计数；达到两次才拒绝该A后续机会。无跟随、未成交和撤单不算原stop。
- 未确认委托／未知状态保留占位。退出时间必须严格早于新触发所在分钟才释放；同一分钟退出不提前释放。
- 待触发期限沿用12个已观察15分钟桶；第5持仓桶MFE不足0.5R退出，最多60桶；沿用周末和长假处理。退出模块只使用原止损和原绝对目标，不套用旧N的分批／阶梯追踪。

## 回测规则与实时报价的边界

执行版本单独标识为 `b5-six-book-v1`。实盘／本地模拟从有效买卖报价执行，不能复刻回测分钟内的理论触价。小时不顺向的一分钟确认由连续观察的执行行情形成：不使用未来分钟，分钟不完整或行情中断不构造确认；确认后进入下一分钟的报价流程，错过该分钟不追补。

新预警必须在收盘后120秒内进入策略；过期信号只记过滤，不补单。实例初始化预热最近64个识别柱的服务去重状态，所有特征仍使用当时完整可得历史前缀。这个启动边界与从远期历史起点持续运行的回测不同。

运行包含实际盘口、账户资金限制、报价采样和人工确认（半自动时）的差异，本次不声称重现22,864.29元历史净额。原冻结研究文件和结果没有被覆盖。
