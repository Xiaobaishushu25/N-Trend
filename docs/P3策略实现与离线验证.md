# P3 策略实现与离线验证

日期：2026-11-13。本地代码实现完成，未部署、未连接真实交易柜台。策略规则以 [P3策略与工程实施规范](P3策略与工程实施规范.md) 为准；本文记录实现入口、配置及验证边界。

## 实现入口

唯一策略 ID 为 `n_p3_v1`，代码版本 `1`；仓位模块为 `risk_budget_v1`，退出模块为 `p3_exit_v1`。三者强制配套，禁止把金额预算或分批退出误接到其他信号策略。废弃候选实现和运行兼容分支已删除。

- `crates/n-core/src/trader/candidates/p3.rs`：复用现有 N 预警源，评分2.5、原有物理与成本过滤、合约/会话保护、A/B退出、注册与预设。
- `crates/n-core/src/trader/candidates/p3/risk_budget.rs`：含手续费及双边各1 tick的0～2手预算，拟报限价和实际成交复核。
- `crates/n-core/src/trader/candidates/p3/tests.rs`：13项规则与边界测试。
- `crates/n-core/src/trader/p3_execution_tests.rs`：10项执行器集成测试，复用本地模拟柜台及 PaperBroker。
- `src/components/TraderInstancesPanel.vue`：新建P3预设、模式、预算和最大手数配置。P3配置冻结入场委托时限为3秒，保留已存在条件单与持仓的参数版本。

## 配置与默认值

从多策略实例界面选择“P3 · 600元预算 / S1与分批追踪”创建；不会因注册预设而自动创建或启动实盘实例。默认仍采用半自动交易控制，模式A；启用交易遵循原实例控制流程。

| 参数 | 默认值 | 规则 |
|---|---|---|
| `risk_budget_yuan` | `600` | 正数且至少0.01元；预算向下取整到分 |
| `max_lots` | `2` | 只能1或2；实际风险超预算时允许正常拒绝为0手 |
| `exit_mode` | `fixed_s1` | 模式A：实际成交数量全部在原结构S1退出 |
| `exit_mode` 可选值 | `hybrid_s1` | 模式B：实际两手时首手S1，确认成交后余仓价格保本；峰值1.6R激活、距离0.8R追踪；实际一手全部S1 |
| `entry_cutoffs` | `{}` | 大写真实合约编号到北京时间截止时刻的映射，例如 `{"PB2701":"2026-12-25 14:50:00"}`；仅提前禁止开仓，不另行定义强平时刻 |
| `fees` / `calendar` | 冻结参考快照 | 沿用现有费用字段与日历校验；P3节前禁入/全平均设在最后收盘前10分钟 |

结构风险仍需至少10 ticks、摩擦不超过20%、risk/ATR14处于[0.75,2.5]、S1计划净RR至少1。实际点值和tick与信号快照不一致时停止新增风险，不能把错误乘数解释成更便宜的交易。

单手预算包含保守往返手续费和不利滑点，风险向上取整到分。B=600、最多两手时，单手含成本风险不超过300允许两手，超过300但不超过600允许一手，超过600放弃。拟报价复核只减批准手数；实际成交后超额或核算异常按公共执行层规则接管和退出。

模式B只根据首手S1任务的实际累计成交完成转换。保本价用真实成交均价并按真实tick向有利方向对齐；初始R在开仓结束后冻结。最新行情已穿过新保护价时立即请求退出，不能回填一笔理想保本成交。部分成交、撤单未知、迟到成交与重启继续由公共执行器管理。

## 时间保护与合约边界

前五个实际观察且完成的15m持仓桶MFE不足0.5R退出；最大持仓60桶。首手平仓尚在途也不能阻塞全仓止损、会话或时间退出。部分开仓改变实际均价和R时同步重算已观察MFE。

周末按真实合约北京时间最后会话收盘前10分钟处理，包含跨午夜。节前使用冻结最后收盘；日历覆盖结束前10分钟停止新增风险并请求全平。参考日历当前覆盖至2026-12-30 15:00，必须及时维护后续冻结快照。

P3主动避开交割月，月份判断采用实际交易日；交割月前最后有效日盘收盘前10分钟开始禁入和请求全平。此规则按商品期货日盘15:00及现有冻结日历保守推导，不能代替逐品种、交易所及账户身份的交割资格审核。账户有更早限制时应配置更早禁入，并在运行前确认已有头寸的退出安排。
