# ABC交易逻辑与跨品种失效深度复核

复核日期：2026-10-27，北京时间。检索范围为本项目的研究基线、research-runs、冻结策略与识别源码，以及 `G:\待处理文件\交易系统` 的原始规格和新N回测核验记录。本次没有重新优化策略或运行新行情回测；另从冻结逐笔重算250笔四品种B5交易的收益算术，结果全部匹配原归档。未修改生产策略。

**直接判断**

“A推动—B回撤—局部反转—沿A方向交易”可以构成待检验的交易假设，但它没有自带正期望。当前证据不足以把整套策略宣布为根本不可能，也已经足够否定“只要ABC画准确，反转后自然有可获利延续”的默认前提。在当前测试范围内，通用品种模板缺乏稳健支持；完整B5在EG有较强的条件历史支持，PVC在部分阶段有支持，JD/SR尚不足。不能把剩余问题默认全归为识别精度。

**1．原始直觉实际包含四个不同命题**

1. 已经出现的A是真正有持续性的推动，而不是区间中的一腿。
2. B是暂时回撤，而不是更大尺度反向运动的起点。
3. 当前反转预警意味着B结束，且价格将先向目标推进，而不是先扫止损。
4. 这种路径能在成交、退出、成本与重复尝试后留下正净额。

前三项都不能单靠给历史折线命名而成立，第四项也不由前三项的“总体方向对”自动推出。事后B终点只能在后续行情中确认；实时策略只能识别B结束的候选。若“识别精准”是事后只保留真正长出C的ABC，便把未来成功写进了信号定义。

可交易问题应表述为：在决策时全部已知信息下，先触目标、先触止损以及超时退出的联合分布，扣除成本后是否优于匹配市场背景。不是问未来某时是否终于沿A方向涨跌。

**2．小止损为什么不能自行创造优势**

在固定毛赢G、毛亏L、平均成本c的简化模型中，E=pG−(1−p)L−c。35%胜率、赢2R、亏1R，在零成本时仅有0.05R期望；若每笔成本0.10R，就变为−0.05R。若实际赢家平均只有1.5R，同样成本下盈亏平衡胜率已达44%。这是算术例子，不是本系统的参数估计。

缩短止损，增加了目标距离/止损距离这个名义比率，也通常更容易被正常波动先触损。没有方向信息的理想连续无漂移价格，在上下固定边界和适当条件下，先到上方G的概率约为L/(G+L)，高名义盈亏比恰好被较低胜率抵消；真实市场不满足所有这些假设，但该例足以说明几何不等于优势。

还要区分“每次亏损金额小”和“成本占风险小”。止损越小，手续费和滑点折算成R可能越大。等现金风险配置还会因更窄止损而增加手数和摩擦。净R若已含成本，不能再重复减成本。

你担心连续小止损吞掉一次成功，数学上完全成立。例如三次各亏1R、一次只赢2R，总额仍为−1R，未计成本。是否能靠少数赢家覆盖，取决于真实盈利尾部与真实失败簇总损失，而不是止损的“小”这个形容词。

**3．代码与你设想的止损语义不完全相同**

当前识别源码 `crates/n-core/src/analyze/event.rs` 的 `pattern_for_current_bar` 将当前预警柱low/high设为S2；`candidate_for` 在该预警整柱另一端外1tick入场，S2外加max(0.1ATR20,1点)缓冲止损。冻结B0定义同样明确沿用原预警S2止损。

因此，S2是当前战术反转候选，不保证是整个已知B的极值，更不保证B已完成右侧确认。突破一根预警柱证明局部突破，不能直接等同整个回调结束。

旧参考版本结构审计中，上半年353/501笔止损仍位于整个已知B区间内；8—10月实际样本119/159笔也是如此。入场时平均已恢复约36%的B幅度，初始风险约1.1—1.2ATR。该表属于旧参考版本，不是最新B5全样本。它解释了模型语义，不应把这些比例机械套给所有版本。

所以，很多战术止损之后父结构仍有可能存在；这不一定是程序错误，但它意味着策略在支付“提前试探”的成本。若把它称为整个B失效，就会混淆风险尺度。

另一方面，B0—B5目标是预警前12根完整15分钟柱中的合格确认转折，无合适目标回S1，并以S1封顶；有第5持仓桶无跟随退出和最长持仓约束。它主要交易回撤后的结构内恢复，而不是无限持有C段的趋势跟踪策略。不能拿理论上的整段大趋势收益替代当前退出实际能兑现的赢家。

**4．“只是止损窄”与“只是确认不够”已经受过直接检验**

旧参考版本固定已接纳入场、成交和绝对目标，关闭部分其他退出以隔离止损：

|上半年固定入场诊断|盈利率|净额/元|
|---|---:|---:|
|原止损|34.7%|−36,009.72|
|1.5倍止损|42.3%|−42,786.95|
|2倍止损|47.1%|−45,878.39|
|整个B极值外止损|40.1%|−37,438.39|

这是隔离机制的诊断，不能与完整策略金额混用。含重新筛选和机会竞争的完整试验也未支持整个B止损：旧参考上半年−21,269.47→−24,677.45元；当时观察版−11,803.88→−15,711.82元。更宽止损确实救回部分交易，同时扩大另一些失败的损失。

最近A优先的识别修订有实质价值：此前小时适配版上半年−11,803.88改善到B0的−6,863.29元，近期16,782.32改善到21,075.34元。但它主要改变机会选择与竞争，不能表述为共同交易的反转预测全变准。

继续把A画得“更干净”、要求B更慢、硬加内部转折确认，没有得到普遍改善。B转折确认试验：B0上半年−6,863.29、近期+21,075.34；全面改价确认后上半年约−265、近期约+10,577。等确认减少一些失败，也消耗到原目标的空间、增加到原止损的距离，并错失赢家。

同样的未越过内部转折状态，上半年表现差、近期表现好；粗形态构成变化不足以解释时期反转。这是描述性证据，尚不能证明某种宏观原因，但不支持“上半年只是识别到更多坏形态”这一单一解释。

**5．鸡蛋路径证据直接解释了“后来走对，为什么仍亏”**

2026原JD去重预警的16柱完整窗口中，68.7%曾有利≥1原R，63.4%也曾不利≥1原R。明确触发后，+1R/−1R已决首次触达的目标先到率44.4%，+2R/−1R为30.1%，均低于对应零成本毛保本率。未决、删失、费用和退出还要另外考虑，该表不是完整策略回测。

199组匹配背景下，ABC的16柱平均MFE为2.31R，匹配中位2.35R；末端方向R也接近。存在大MFE，不证明反转信号有超额信息，因为同背景普通时点也能经历较大双向波动。

这是原始预警层的结论，不是过滤后B5或新收回模块的结论。新“失守S0后收回”是另一机制，2026观察改善不能覆盖2025年9—12月迁移失败：F2S8组合主净额−280.58元，原收回组合−400.54元。不能用新开发赢家绕开跨期证据。

全22品种、2025年9月至2026年10月B5原名单主场景也有PP+3,851、EB+2,913、BU+5,449.48等正贡献。因此“只有EG盈利”若理解为全部历史的事实并不准确；若理解为EG证据更集中、更强，则基本符合归档。两个名单、时期的EG数字也不能混加。

为什么EG强，已有证据能回答到交易路径这一层：

- 盈利端：EG目标退出率43.2%，PVC32.4%、SR28.6%；EG平均盈利2.035R，也高于后两者约1.56R。EG与PVC亏损幅度接近，因此主要差别在目标兑现与赢单幅度，而非EG拥有神奇止损。
- 现金风险：平均一手初始现金风险EG约353元，PVC145、JD239、SR162元。EG现金利润的一部分来自承担更多风险；但归一到R仍领先PVC/SR。
- 频率：EG88笔、JD19笔。JD历史累计收益偏低确有机会供给和资格转化因素，不能全归于方向差。近期JD单笔质量接近零，又说明增加频率并非充分解法。
- 成本：固定既有路径做摩擦会计还原，EG摩擦吞掉还原前净额约13.2%，PVC60.1%、SR83.7%。这不是重新运行的零成本策略。EG/PVC候选ATR tick中位接近，不能把差异都解释成EG波动更大。
- 尾部：EG去掉最佳5笔仍赚5,952元，14/17个活跃月盈利；不能说只靠一单运气。但2026Q2亏损，去掉最佳10笔后整体略负，10月延迟情景也转亏，仍有尾部和状态依赖。

“产业供需让EG更适配”可以作为待测解释，但本次没有时点一致的供需变量和因果识别，不能将其写成已证实原因。日线有趋势也不保证15分钟回撤结构具备可成交优势。

**7．最关键的反证：ABC标签脱离完整计划并无已证明优势**

2026年4—10月已有覆盖，固定四品种：完整B5主场景105笔+7,443.12元；ABC信号接统一1ATR止损、2R目标与统一执行，358笔−11,952.77元。后者还没有优于匹配随机时点。

这不能用来否定原B5，因为它同时改变了几何和执行；但直接反驳了“ABC预警本身已具有足够强入场优势”。保留原止损/目标距离、入场缓冲和执行指令后，原时点风险归一收益在条件随机对照主场景约98百分位，最严压力降至70.4百分位。支持的是特定时点、计划和执行的配合，百分位不是98%成功概率或校正后的统计显著性。

**8．重复止损合理担忧，尚不是已证实主因**

原2026开发窗口，B5在B4上增加“同A两次原stop后停止重试”，仅再剔除3笔、改善225元。B3中重复A簇的首次交易合计−9,856.64元，后续交易合计+4,393.78元；整个重复簇亏损不能全归于重试。有些再次尝试抓到了真正启动。

这不证明重复止损永远无害；簇标签也可能不能完整代表同一更大行情。但已有证据不支持“禁止重试就是解法”。若继续诊断，应按严格事前定义的父结构核算所有尝试的现金损失、成本、成功兑现和占用，而非事后挑最后成功的入场展示高盈亏比。

**9．研究量大，为什么仍不能确定**

真实合约分钟核验、午夜聚合、ATR、上游去重和触发占用修复均有价值，必须沿用修复后的统一口径。G盘P2/P3早期正收益与后来修复结果并非同一金额：例如近期P2从18,004.82变为11,184.56元，不能将不同研究轮次拼成一条稳定证据链。实现复现通过只说明引擎和记录一致，并非证明泛化。

同一历史上反复试A选择、止损、目标、确认、并发、名单和季度开关，形成了大量研究自由度。最终规则条数少也不能抹去此前选优。分钟成交数、参数场景数、随机次数和数十万次回放，都不是相同数量的独立市场环境。化工品共享状态，多条预警共享趋势，信息量进一步少于表面笔数。

外部方法论也支持这个边界：Bailey等的[回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)讨论从多次试验中选优造成的样本外退化。其论文不能证明本项目已经过拟合到某个概率；本次未计算PBO。AQR的[长期趋势跟踪研究](https://www.aqr.com/insights/research/journal-article/a-century-of-evidence-on-trend-following-investing)说明特定趋势策略可以在其研究尺度、市场和成本条件下有效，不能为15分钟ABC形态直接背书。

**10．后续最有价值的决策**

保留ABC作为候选生成与风险结构语言，撤销“它理应在大多数品种赚钱”的默认前提。EG完整B5值得保留为优先验证对象；PVC列为有阶段支持的挑战者；JD/SR允许少做、停止扩频或另证机制。上述是研究判断，本次没有修改实际名单或交易配置。

已有的统一放宽止损、统一确认、缩短止盈、早进、画远目标、C结构退出，大多已测试。下一轮应先查本报告来源，避免换名称重复扫描。也不能因为发现目标封顶，就直接取消封顶；JD远目标曾因改变资格而引入大量劣质新单，必须拆开资格和纯退出效果。

若继续研究，建议只保留三类可证伪问题：

1. **时点是否有信息**：保留完整原计划，与匹配方向、时段、波动和市场背景的对照比较。现有2026诊断已有结果，应优先在冻结后的新增数据验证延续，而非再扩大同历史随机次数。
2. **风险尺度是否匹配**：明确当前预警点、整个已知B极值和已确认C结构的不同含义；按整个事前父结构算总尝试成本与收益。已有B宽止损失败是对照，新假设须解释为什么本次会不同。
3. **盈利端是否可持续**：在不放松入场资格的前提下，核查EG目标到达率、赢单净R和执行压力在后续时间块能否维持。若要研究延伸退出，先冻结原机会集合并完整重竞争，不能用未来MFE倒推完美目标。

验收应预先固定时间段、风险与可接受的成本压力，披露全部失败分支，并检查扣费后的增量、浮动权益与实际执行。无需要求每个月盈利，也不能以“还有参数没找到”无限延长一个失败机制。若在合理执行成本、新时间块和同风险基准下始终不能留下增量，应停止把ABC当交易入场依据；它仍可作为描述工具。

最终判断：你对“小止损可能被反复支付，偶尔一次正确也覆盖不了”的怀疑是有直接数学与本地路径证据支持的。需要修正的是从图形合理性跳到正期望的推论。现有证据最符合“特定品种、特定结构计划和执行方式下可能有条件优势”，并不符合“通用ABC已经有效，只差把图画准”。
